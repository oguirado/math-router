# Catalogue

The catalogue of the 719 papers is [Catalogo_Math.md](Catalogo_Math.md). The file name is kept because the built index and the release records refer to it. It is generated from the papers and lists the standards, the coordinate grammar (section 0), the subject index, the family register and the per-paper rows. Machine-readable navigation starts at `catalogue/subjects.json`; the layout is described in `ARCHITECTURE.md`.
