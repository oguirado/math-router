## 1. Abstract and result contract

> We construct an explicit counterexample to the Abhyankar–Sathaye conjecture: a noncoordinate polynomial in four complex variables whose zero fibre is affine three-space. Adjoining variables gives counterexamples in every ambient dimension at least four.

- **C1** (counterexample, [source](#stmt-thm-main)): The polynomial $F$ defined in <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a>–<a href="#eq:F" data-reference-type="eqref" data-reference="eq:F">[eq:F]</a> satisfies $$R/(F)\cong\mathbb C^{[3]}, \qquad \mathop{\mathrm{\nabla}}F(2,0,-1/2,1/2)=0.$$ Consequently $F$ is not a coordinate of $R$.
  - Explanation: The zero fibre has a polynomial coordinate presentation, while an ambient critical point obstructs coordinate status.
- **C2** (construction, [source](#stmt-cor-dimension)): For every integer $n\ge4$, there is a polynomial $f\in\mathbb C[z_1,\ldots,z_n]$ such that $\mathbb C[z_1,\ldots,z_n]/(f)\cong\mathbb C^{[n-1]}$ and $f$ is not a coordinate.
  - Explanation: Adjoining independent variables preserves the polynomial quotient and the ambient critical-point obstruction.
- **C3** (theorem, [source](#stmt-lem-lift)): Let $B$ be a ring and let $h,x,y,s\in B$ satisfy $$x^2+y^3=hs,\qquad (h,y)=B. \label{eq:base}$$ Then the $B$-algebra $$C=B[U,V,W]/\bigl(U^3+hV-x,\,-U^2+hW-y,\, S(h,U,V,W)-s\bigr)$$ is isomorphic to $B[T]$, where $T$ is an indeterminate.
  - Explanation: Compatible linear equations and a unit-ideal certificate give inverse polynomial maps over a commutative base ring, including bases with zero divisors.

## 2. Definitions, validity and bounds

- **Polynomial ring notation** ([source](#sec:introduction)): Here $\mathbb C^{[m]}$ denotes a polynomial ring in $m$ independent variables, and the displayed isomorphism is required to fix $\mathbb C$.
- **Cusp-derived polynomials** ([source](#eq:xyz)): In $R=\mathbb C[h,u,v,w]$, put $$\label{eq:xyz} \begin{aligned} x&=u^3+hv,\qquad y=-u^2+hw,\\ s&=S(h,u,v,w) :=2u^3v+3u^4w+h(v^2-3u^2w^2)+h^2w^3. \end{aligned}$$
- **Defining polynomial** ([source](#eq:F)): Define $p$ and $F$ by $$p(x,y,s)=-2s^2x+3sy^2-3s^3y, \qquad F=h-p(x,y,s)-1. \label{eq:F}$$
- **Auxiliary base algebra** ([source](#eq:B)): Using independent indeterminates $h,x,y,s$, form the auxiliary algebra $$B=\mathbb C[h,x,y,s]/\bigl(h-1-p(x,y,s),\ x^2+y^3-sh\bigr). \label{eq:B}$$
- **Translation coordinates** ([source](#eq:shift)): For formal $x,y,s$, the translation $$X=x+s^3,\qquad Y=y-s^2 \label{eq:shift}$$ satisfies $$X^2+Y^3=x^2+y^3-sp(x,y,s). \label{eq:shiftidentity}$$

### Panel 1 - epistemic contract

- **I-cusp**: The displayed polynomials satisfy x^2+y^3=hs.
- **I-ambient**: The shifted polynomials satisfy X^2+Y^3=s(1+F).
- **I-critical**: The specified point has F=-1 and vanishing gradient.
- **I-fibre**: The zero-fibre quotient is a polynomial ring in three variables.

### Panel 2 - negative knowledge

- **A-zero**: Conclude ambient coordinate status from an affine-space zero fibre. -> The construction has a critical point on another fibre.
- **A-dimension**: Use this example to resolve the three-variable case. -> The stated construction and extension cover ambient dimensions at least four.
- **A-division**: Implement the lifting lemma by dividing by h or y. -> Neither coefficient must be a unit, and the base can have zero divisors.

### Panel 3 - reference implementation and oracle

Applicability: `constructive`. Finite straight-line polynomial construction and exact evaluation of its critical-point witness; this is not a coordinate-recognition algorithm.

```python
# INPUTS: JSON list of at most 100 rational quadruples [h,u,v,w].
# PRECONDITIONS: Each coordinate is a rational string with a nonzero denominator.
# OUTPUTS: JSON rows [x,y,s,p,X,Y,F,dF/dh,dF/du,dF/dv,dF/dw] as rational strings.
# TIME: O(N) exact arithmetic operations; bit cost depends on input size.
# SPACE: O(N) output storage plus constant-size exact derivative state.
# ARITHMETIC: Certified exact python-flint fmpq; no floating point.
# FAILURE: Invalid input raises an exception and exits nonzero; no division by h or s.
import sys,json
from flint import fmpq
class Jet:
    def __init__(self,a,d=None):
        self.a=fmpq(a); self.d=d if d is not None else [fmpq(0)]*4
    def __add__(self,b):
        b=b if isinstance(b,Jet) else Jet(b)
        return Jet(self.a+b.a,[x+y for x,y in zip(self.d,b.d)])
    __radd__=__add__
    def __neg__(self): return Jet(-self.a,[-x for x in self.d])
    def __sub__(self,b): return self+-b if isinstance(b,Jet) else self+Jet(-b)
    def __mul__(self,b):
        b=b if isinstance(b,Jet) else Jet(b)
        return Jet(self.a*b.a,[x*b.a+self.a*y for x,y in zip(self.d,b.d)])
    __rmul__=__mul__
    def __pow__(self,n):
        assert isinstance(n,int) and 0<=n<=6
        out=Jet(1)
        for _ in range(n): out=out*self
        return out
points=json.loads(sys.stdin.read())
assert isinstance(points,list) and 1<=len(points)<=100
rows=[]
for point in points:
    assert len(point)==4 and all(isinstance(z,str) for z in point)
    jets=[]
    for i,z in enumerate(point):
        d=[fmpq(0)]*4; d[i]=fmpq(1); jets.append(Jet(fmpq(z),d))
    h,u,v,w=jets
    x=u**3+h*v
    y=-u**2+h*w
    s=2*u**3*v+3*u**4*w+h*(v**2-3*u**2*w**2)+h**2*w**3
    p=-2*s**2*x+3*s*y**2-3*s**3*y
    F=h-p-1
    X=x+s**3; Y=y-s**2
    assert (x**2+y**3-h*s).a==0
    assert (X**2+Y**3-s*(1+F)).a==0
    rows.append([str(z.a) for z in [x,y,s,p,X,Y,F]]+[str(z) for z in F.d])
print(json.dumps(rows,separators=(',',':')))
```

## 7. Complete mathematical paper


We construct an explicit counterexample to the Abhyankar–Sathaye conjecture: a noncoordinate polynomial in four complex variables whose zero fibre is affine three-space. Adjoining variables gives counterexamples in every ambient dimension at least four.

<a id="sec:introduction"></a>
### Introduction and statement

The Abhyankar–Sathaye conjecture asks whether a polynomial $f\in\mathbb C[z_1,\ldots,z_n]$ satisfying $$\mathbb C[z_1,\ldots,z_n]/(f)\cong\mathbb C^{[n-1]}$$ must be a coordinate, that is, the first component of a polynomial automorphism of $\mathbb A^n_{\mathbb C}$. Here $\mathbb C^{[m]}$ denotes a polynomial ring in $m$ independent variables, and the displayed isomorphism is required to fix $\mathbb C$. Geometrically, the question asks whether every hypersurface embedding $\mathbb A^{n-1}_{\mathbb C}\hookrightarrow\mathbb A^n_{\mathbb C}$ can be carried to a coordinate hyperplane by an ambient polynomial automorphism.

For $n=2$, the question is answered affirmatively by the Abhyankar–Moh–Suzuki Theorem <a id="pm-cite-1"></a>[[AM](#ref-AM), [Suzuki](#ref-Suzuki)]. The higher-dimensional problem belongs to a family of questions about polynomial maps with affine-space fibres. Sathaye <a id="pm-cite-2"></a>[[Sathaye](#ref-Sathaye), pp. 1–2] distinguished the coordinate, or epimorphism, question from the weaker question whether an affine-space zero fibre forces all fibres to be affine space. A coordinate polynomial defines a projection after an automorphism, so its fibres are all isomorphic to $\mathbb A^{n-1}_{\mathbb C}$; an isomorphism of the zero fibre alone supplies no such global trivialization. Kraft <a id="pm-cite-3"></a>[[Kraft](#ref-Kraft), 4] surveys the embedding problem and its relation to algebraic group actions. Among the early affirmative results, Sathaye <a id="pm-cite-4"></a>[[Sathaye](#ref-Sathaye)] proved rectifiability for planes defined by polynomials linear in one of three variables in characteristic zero, and Russell <a id="pm-cite-5"></a>[[Russell](#ref-Russell), Theorem 2.3] extended this result to arbitrary fields.

In four variables, Kaliman, Vénéreau and Zaidenberg <a id="pm-cite-6"></a>[[KVZ](#ref-KVZ), Theorem 4.2(a)] and Maubach <a id="pm-cite-7"></a>[[Maubach](#ref-Maubach), Corollaries 4.2–4.3] established affirmative results for equations $a(x)y+b(x,z,t)$ with $a\ne0$: an affine-three-space zero fibre can be straightened by an ambient automorphism. Here $x,y,z,t$ are independent variables, and the coefficient of $y$ depends on only one of them. Further algebraic treatments appear in work of El Kahoui, Essamaoui and Ouali <a id="pm-cite-8"></a>[[EEO](#ref-EEO)] and Ghosh, Gupta and Pal <a id="pm-cite-9"></a>[[GGPthreefold](#ref-GGPthreefold)]. Ghosh, Gupta and Pal also study linear hypersurfaces with multivariable coefficients under additional hypotheses on the coefficients and their divisors <a id="pm-cite-10"></a>[[GGP](#ref-GGP), Theorem 4.11]. Ghosh <a id="pm-cite-11"></a>[[Ghosh](#ref-Ghosh), Theorem 1.4] proves an affirmative embedding theorem in characteristic zero for $a(x_m)b(x_1,\ldots,x_{m-1})y+f(z,t)+x_m$, where the displayed variables are independent, $b\ne0$, and $a$ has at least two distinct roots over the algebraic closure. These results illustrate the role of restrictions on the defining equation; an abstract polynomial presentation of the quotient does not itself provide an automorphism of the ambient polynomial ring.

We give a counterexample in ambient dimension four, and hence in every ambient dimension at least four. The three-variable case is not addressed.

<a id="eq:xyz"></a>
<a id="eq:F"></a>
The construction starts from the cusp parametrization $(u^3,-u^2)$ and perturbs its two entries by independent multiples of $h$. In $R=\mathbb C[h,u,v,w]$, put $$\label{eq:xyz}
  \begin{aligned}
    x&=u^3+hv,\qquad y=-u^2+hw,\\
    s&=S(h,u,v,w)
       :=2u^3v+3u^4w+h(v^2-3u^2w^2)+h^2w^3.
  \end{aligned}$$ Since $x^2+y^3$ vanishes modulo $h$, it is divisible by $h$ in $R$. The displayed polynomial $s$ is its quotient, so $x^2+y^3=hs$. Define $p$ and $F$ by $$p(x,y,s)=-2s^2x+3sy^2-3s^3y,
  \qquad F=h-p(x,y,s)-1. \label{eq:F}$$ Thus $F$ is a polynomial in the four independent variables $h,u,v,w$.

<a id="stmt-thm-main"></a>
<div id="thm:main" class="theorem">

**Theorem 1**. *The polynomial $F$ defined in <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a>–<a href="#eq:F" data-reference-type="eqref" data-reference="eq:F">[eq:F]</a> satisfies $$R/(F)\cong\mathbb C^{[3]},
  \qquad
  \mathop{\mathrm{\nabla}}F(2,0,-1/2,1/2)=0.$$ Consequently $F$ is not a coordinate of $R$.*

</div>

The critical point $P=(2,0,-1/2,1/2)$ lies on the fibre $F=-1$. The zero fibre is smooth, since it is isomorphic to affine three-space.

<a id="stmt-cor-dimension"></a>
<div id="cor:dimension" class="corollary">

**Corollary 2**. *For every integer $n\ge4$, there is a polynomial $f\in\mathbb C[z_1,\ldots,z_n]$ such that $\mathbb C[z_1,\ldots,z_n]/(f)\cong\mathbb C^{[n-1]}$ and $f$ is not a coordinate.*

</div>

Shpilrain and Yu <a id="pm-cite-12"></a>[[SY](#ref-SY), 1] used the ambient critical locus to distinguish isomorphic hypersurfaces with inequivalent embeddings. They asked whether the gradient must be nowhere zero when the zero fibre is isomorphic to a coordinate hyperplane. Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a> gives a negative answer in ambient dimension four, and Corollary <a href="#cor:dimension" data-reference-type="ref" data-reference="cor:dimension">2</a> preserves this obstruction after adjoining variables. The distinction is between the intrinsic geometry of one fibre and the behaviour of its defining polynomial on the ambient space.

The main algebraic ingredient is Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">3</a>. It turns a presentation over a commutative base ring $B$ with $x^2+y^3=hs$ and $(h,y)=B$ into a polynomial extension of that base. Two compatible linear equations, with coefficients generating the unit ideal, give explicit inverse maps even when the base has zero divisors. In our example, a translation identifies the auxiliary algebra cut out by $x^2+y^3=hs$ and $h=1+p(x,y,s)$ with a polynomial ring in two variables; the lemma supplies the third variable. This proves that the zero fibre is affine space. An identity in the original four-variable ring then exhibits a critical point on the fibre over $-1$, which rules out a coordinate.

The polynomials in <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a> also have an invariant-theoretic interpretation. The triangular derivation $D=h\partial_u-3u^2\partial_v+2u\partial_w$ of $R$ annihilates $h,x,y,s$. They arise in the triangular monomial kernel calculation of Maubach <a id="pm-cite-13"></a>[[MaubachMonomial](#ref-MaubachMonomial), proof of Theorem 3.2, case (3)]. The proof below uses the cusp relation directly through Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">3</a>.

Section <a href="#sec:lifting" data-reference-type="ref" data-reference="sec:lifting">2</a> proves the lifting lemma over an arbitrary commutative base ring. Section <a href="#sec:mainproof" data-reference-type="ref" data-reference="sec:mainproof">3</a> identifies the auxiliary algebra, establishes the zero-fibre isomorphism, and proves the critical-point obstruction and its persistence after adjoining variables. Appendix <a href="#app:coordinates" data-reference-type="ref" data-reference="app:coordinates">4</a> records the resulting polynomial coordinates and their inverse.

<a id="sec:lifting"></a>
### An elementary lifting lemma

The next lemma provides the polynomial parameter used to identify the zero fibre. Its unit-ideal hypothesis allows us to solve two compatible linear equations without dividing by either coefficient. This point matters because the coefficients need not be units, and the base ring may have zero divisors.

In the following statement, $S(H,U,V,W)$ denotes the universal polynomial specified in <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a>, with the indicated arguments. All rings are commutative with identity.

<a id="stmt-lem-lift"></a>
<div id="lem:lift" class="lemma">

**Lemma 3**. *Let $B$ be a ring and let $h,x,y,s\in B$ satisfy <a id="eq:base"></a>$$x^2+y^3=hs,\qquad (h,y)=B. \label{eq:base}$$ Then the $B$-algebra $$C=B[U,V,W]/\bigl(U^3+hV-x,\,-U^2+hW-y,\,
                     S(h,U,V,W)-s\bigr)$$ is isomorphic to $B[T]$, where $T$ is an indeterminate.*

</div>

<details id="proof-stmt-lem-lift"><summary>Proof of stmt-lem-lift</summary>

<a id="eq:bezout"></a>
<a id="eq:Clinear"></a>
*Proof.* We first make one relation linear, then eliminate $W$ using the unit-ideal hypothesis, and finally identify the remaining algebra with a polynomial ring in one variable. Choose $\alpha,\beta\in B$ with $$\alpha h+\beta y=1. \label{eq:bezout}$$ Make the polynomial substitution $G=V+UW$, whose inverse is $V=G-UW$. Modulo the relation $hW=y+U^2$, direct expansion gives $$S(h,U,G-UW,W)=hG^2-2UyG+y^2W.$$ The first defining relation becomes $hG-yU=x$ modulo the same relation. Consequently $$C\cong B[U,G,W]/\bigl(hG-yU-x,\ hW-y-U^2,\
                       y^2W-s+hG^2-2UyG\bigr). \label{eq:Clinear}$$

<a id="eq:compat"></a>
<a id="eq:Wlinear"></a>
Put $A=B[U,G]/(hG-yU-x)$ and, in $A$, set $$a=y+U^2,\qquad b=s-hG^2+2UyG.$$ The last two equations in <a href="#eq:Clinear" data-reference-type="eqref" data-reference="eq:Clinear">[eq:Clinear]</a> are $hW=a$ and $y^2W=b$. They are compatible, since $$y^2a-hb=(hG-yU)^2+y^3-hs=x^2+y^3-hs=0. \label{eq:compat}$$ Moreover, if $r=\alpha(1+\beta y)$ and $q=\beta^2$, then $$rh+qy^2=(1-\beta y)(1+\beta y)+\beta^2y^2=1.$$ It follows that $$W_0=ra+qb \label{eq:Wlinear}$$ solves both equations: <a href="#eq:compat" data-reference-type="eqref" data-reference="eq:compat">[eq:compat]</a> gives $hW_0=(rh+qy^2)a=a$ and $y^2W_0=(rh+qy^2)b=b$. In $A[W]$ one has $$W-W_0=r(hW-a)+q(y^2W-b),$$ while $hW-a=h(W-W_0)$ and $y^2W-b=y^2(W-W_0)$. Hence $$(hW-a,\ y^2W-b)=(W-W_0).$$ Evaluation at $W_0$ therefore gives $A[W]/(hW-a,y^2W-b)\cong A$. By <a href="#eq:Clinear" data-reference-type="eqref" data-reference="eq:Clinear">[eq:Clinear]</a>, this proves $C\cong A$.

<a id="eq:UG"></a>
Finally, define a $B$-algebra map $A\to B[T]$ by $$U=hT-\beta x,\qquad G=yT+\alpha x. \label{eq:UG}$$ Its inverse is given by $T\mapsto\alpha U+\beta G$. Indeed, $hG-yU=x$ follows from <a href="#eq:bezout" data-reference-type="eqref" data-reference="eq:bezout">[eq:bezout]</a>; in $A$ one has $$h(\alpha U+\beta G)=U+\beta x,\qquad
  y(\alpha U+\beta G)=G-\alpha x,$$ and substitution of <a href="#eq:UG" data-reference-type="eqref" data-reference="eq:UG">[eq:UG]</a> gives $\alpha U+\beta G=T$. These verify both composites. Thus $C\cong A\cong B[T]$. In the original variables, the parameter is $$T=\alpha U+\beta(V+UW).$$ Its inverse recovers $U,G$ by <a href="#eq:UG" data-reference-type="eqref" data-reference="eq:UG">[eq:UG]</a>, then $W$ by <a href="#eq:Wlinear" data-reference-type="eqref" data-reference="eq:Wlinear">[eq:Wlinear]</a> and $V=G-UW$. ◻

</details>

<a id="sec:mainproof"></a>
### The affine-space fibre and the critical point

We first identify the base algebra to which Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">3</a> applies. After obtaining the coordinates on the zero fibre, we use the same polynomial identities in the ambient ring to locate a critical point on another fibre.

<details id="proof-stmt-lem-lift-2"><summary>Proof of stmt-lem-lift</summary>

<a id="eq:cusp"></a>
<a id="eq:shift"></a>
<a id="eq:shiftidentity"></a>
*Proof of Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a>.* First, direct expansion of <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a> gives $$x^2+y^3=hs. \label{eq:cusp}$$ For formal $x,y,s$, the translation $$X=x+s^3,\qquad Y=y-s^2 \label{eq:shift}$$ satisfies $$X^2+Y^3=x^2+y^3-sp(x,y,s). \label{eq:shiftidentity}$$ Here the terms $s^6$ from the square and cube cancel.

<a id="eq:B"></a>
<a id="eq:Bplane"></a>
<a id="eq:Bparam"></a>
Using independent indeterminates $h,x,y,s$, form the auxiliary algebra $$B=\mathbb C[h,x,y,s]/\bigl(h-1-p(x,y,s),\ x^2+y^3-sh\bigr).
  \label{eq:B}$$ We use the same symbols for their residue classes in $B$. This is a new presentation: at this stage $x,y,s$ are independent generators before passage to the quotient, rather than the polynomials in <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a>. Eliminating $h$ and applying the invertible translation <a href="#eq:shift" data-reference-type="eqref" data-reference="eq:shift">[eq:shift]</a> over $\mathbb C[s]$ gives $$B\cong\mathbb C[X,Y,s]/(X^2+Y^3-s)\cong\mathbb C[X,Y]. \label{eq:Bplane}$$ The inverse presentation is explicitly $$s=X^2+Y^3,\quad x=X-s^3,\quad y=Y+s^2,
  \quad h=1+p(x,y,s). \label{eq:Bparam}$$

The elements $h,y$ generate the unit ideal in $B$. Indeed, modulo $(h,y)$, the two defining equations give $x^2=0$ and $1=2s^2x$; squaring the latter gives $1=0$. Hence $B/(h,y)$ is the zero ring.

<a id="eq:fiber"></a>
Form the algebra in Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">3</a> over this $B$, using lower-case $u,v,w$ for its three added variables. Its presentation is $$C=B[u,v,w]/\bigl(u^3+hv-x,\,-u^2+hw-y,\,
                      S(h,u,v,w)-s\bigr).$$ In the polynomial ring on $h,x,y,s,u,v,w$, the last three equations eliminate $x,y,s$. The relation $x^2+y^3-sh$ then becomes the zero polynomial by <a href="#eq:cusp" data-reference-type="eqref" data-reference="eq:cusp">[eq:cusp]</a>, and the other relation in <a href="#eq:B" data-reference-type="eqref" data-reference="eq:B">[eq:B]</a> becomes exactly $F$. Thus $C\cong R/(F)$. Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">3</a> and <a href="#eq:Bplane" data-reference-type="eqref" data-reference="eq:Bplane">[eq:Bplane]</a> now give $$R/(F)\cong C\cong B[T]\cong\mathbb C[X,Y,T]. \label{eq:fiber}$$

<a id="eq:ambient"></a>
It remains to show that $F$ is not a coordinate. Return to $R$, with $X=x+s^3$ and $Y=y-s^2$ now interpreted using <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a>. Equations <a href="#eq:cusp" data-reference-type="eqref" data-reference="eq:cusp">[eq:cusp]</a>, <a href="#eq:F" data-reference-type="eqref" data-reference="eq:F">[eq:F]</a>, and <a href="#eq:shiftidentity" data-reference-type="eqref" data-reference="eq:shiftidentity">[eq:shiftidentity]</a> give the ambient polynomial identity $$X^2+Y^3=s(1+F). \label{eq:ambient}$$ At $P=(2,0,-1/2,1/2)$ in the variable order $(h,u,v,w)$, the values are $$x=-1,\quad y=1,\quad s=1,\quad p=2,
  \qquad X=Y=0,\quad F=-1.$$ Differentiating <a href="#eq:ambient" data-reference-type="eqref" data-reference="eq:ambient">[eq:ambient]</a> gives $$2X\,dX+3Y^2\,dY=(1+F)\,ds+s\,dF.$$ At $P$ this reduces to $0=dF(P)$, so $\mathop{\mathrm{\nabla}}F(P)=0$.

We now use the ambient critical-point obstruction emphasized by Shpilrain and Yu <a id="pm-cite-14"></a>[[SY](#ref-SY), 1]. If a polynomial automorphism had $F$ as its first component, its Jacobian matrix at $P$ would have a zero first row. But the chain rule applied to the automorphism and its polynomial inverse makes that matrix invertible. This contradiction proves that $F$ is not a coordinate. ◻

</details>

<details id="proof-stmt-lem-lift-3"><summary>Proof of stmt-lem-lift</summary>

*Proof of Corollary <a href="#cor:dimension" data-reference-type="ref" data-reference="cor:dimension">2</a>.* For $n>4$, use the same $F$ in $R[z_1,\ldots,z_{n-4}]$. Equation <a href="#eq:fiber" data-reference-type="eqref" data-reference="eq:fiber">[eq:fiber]</a> shows that the quotient is a polynomial ring in $n-1$ variables. All derivatives of $F$ in the added variables vanish, and its original four derivatives vanish at $P$. Thus the extended polynomial has a critical point at $(P,0,\ldots,0)$, and the same Jacobian argument rules out a coordinate. The case $n=4$ is Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a>. ◻

</details>

<a id="app:coordinates"></a>
### Explicit coordinates on the zero fibre

The proof of Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a> already supplies both directions of the isomorphism. We collect them here, including a polynomial certificate for the unit-ideal condition, so that the parametrization can be used directly.

<a id="eq:alphabeta"></a>
To make the isomorphism <a href="#eq:fiber" data-reference-type="eqref" data-reference="eq:fiber">[eq:fiber]</a> explicit, take in the algebra $B$ of <a href="#eq:B" data-reference-type="eqref" data-reference="eq:B">[eq:B]</a> $$\begin{aligned}
  \alpha&=1+2s^2x+4s^5,\notag\\
  \beta&=(3s^3-3sy)(1+2s^2x)-4s^4y^2. \label{eq:alphabeta}
\end{aligned}$$ The following identity in the free polynomial ring proves $\alpha h+\beta y=1$ in $B$: <a id="eq:certificate"></a>$$\alpha h+\beta y-1
  =(1+2s^2x)(h-1-p)-4s^4(x^2+y^3-sh). \label{eq:certificate}$$

The three polynomial coordinates on $F=0$ are <a id="eq:fibercoords"></a>$$X=x+s^3,\qquad Y=y-s^2,\qquad
  T=\alpha u+\beta(v+uw), \label{eq:fibercoords}$$ with all expressions interpreted by <a href="#eq:xyz" data-reference-type="eqref" data-reference="eq:xyz">[eq:xyz]</a> and <a href="#eq:alphabeta" data-reference-type="eqref" data-reference="eq:alphabeta">[eq:alphabeta]</a>. Together they define a map from the zero fibre to $\mathbb A^3_{\mathbb C}$. Conversely, start from independent $X,Y,T$, reconstruct $s,x,y,h$ by <a href="#eq:Bparam" data-reference-type="eqref" data-reference="eq:Bparam">[eq:Bparam]</a>, and compute $\alpha,\beta$ by <a href="#eq:alphabeta" data-reference-type="eqref" data-reference="eq:alphabeta">[eq:alphabeta]</a>. Set <a id="eq:explicitinverse"></a>$$\begin{aligned}
  u&=hT-\beta x,\qquad g=yT+\alpha x,\notag\\
  w&=\alpha(1+\beta y)(y+u^2)
        +\beta^2(s-hg^2+2uyg),\notag\\
  v&=g-uw. \label{eq:explicitinverse}
\end{aligned}$$ These are exactly the inverse maps from Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">3</a>. In particular, they are defined on every point of $\mathbb A^3_{\mathbb C}$ and every point of the zero fibre; no open subset has been removed.
