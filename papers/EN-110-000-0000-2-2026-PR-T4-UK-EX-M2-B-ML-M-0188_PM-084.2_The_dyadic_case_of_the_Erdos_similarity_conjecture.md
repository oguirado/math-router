## 1. Abstract and result contract

> We construct a compact subset of the unit interval, of measure arbitrarily close to one, that contains no affine copy of the dyadic sequence $`\{2^{-n}:n\ge1\}`$. The conclusion holds for every translation and every nonzero real dilation, of either sign, proving the dyadic case of the Erdős similarity conjecture.

- **C1** (theorem, [source](#stmt-thm-main)): For every $\eta\in(0,1)$, there is a compact set $E_\eta\subseteq[0,1]$ with $m(E_\eta)>1-\eta$ such that $$\text{for every }x\in\mathbb R\text{ and every }s\in\mathbb R\setminus\{0\}, \quad x+sD\nsubseteq E_\eta.$$ Equivalently, for every such $x,s$ there is an integer $n\ge1$ with $x+s2^{-n}\notin E_\eta$.
  - Explanation: A compact subset of the unit interval can have measure arbitrarily close to one while excluding every signed affine copy of the dyadic sequence.
- **C2** (bound, [source](#stmt-lem-periodic)): For every $p\in(0,1)$, there exists an open $1$-periodic set $H\subseteq\mathbb R$ such that $\rho(H)\le6p$ and $$\forall x\in\mathbb R\ \forall t\in[1,2]\ \exists n\in\mathbb Z_{\ge1}: \qquad x+t2^{-n}\in H.$$
  - Explanation: An open periodic set of controlled density hits every translated dyadic sequence at every normalized scale.
- **C3** (conditional_result, [source](#stmt-lem-stable)): The set $G$ is measurable and $1$-periodic, and $\rho(G^c)<p$. For every $x\in G$, every window $W_e$, every $n\in W_e$, every $t\in[1,2]$, and every window $W_f$ earlier than $W_e$, $$J_{b_f}(x+t2^{-n})=J_{b_f}(x). \label{eq:stable-keys}$$ These assertions include centers lying on grid boundaries.
  - Explanation: Separated windows preserve all earlier grid keys for stable centers, including centers on boundaries.
- **C4** (bound, [source](#stmt-lem-first-default)): For every fixed $x\in\mathbb R$, $$\mathbb P\bigl(\text{the path of \(x\) never chooses child \(M\)}\bigr) = (1-2^{1-M})^d<p.$$
  - Explanation: Independent routing decisions make a default choice likely along the center path.
- **C5** (conditional_result, [source](#stmt-lem-routing)): For every outcome in $\xi$, every $i<M$, every $n\in W_{e_i}$, and every $t\in[1,2]$, the actual root path of $y_n(t)$ reaches $U$ and rejects children $1,\ldots,i-1$ there. In particular, $$\label{eq:local-hit} Q_i(y_n(t))=1 \quad\Longrightarrow\quad y_n(t)\in B.$$
  - Explanation: Stable earlier keys preserve the required ancestor route and earlier rejections; local success implies membership in the selected set.
- **C6** (bound, [source](#stmt-lem-fixed-scale)): Fix a stable center $x$ and an atom $\xi$ of the center-exposure sigma-field $\mathcal F_x$ in <a href="#eq:center-exposure" data-reference-type="eqref" data-reference="eq:center-exposure">[eq:center-exposure]</a>, on which the first default node $U$ exists. Let $h$ be its height, put $r=r_h$, and use the local predicates $Q_i$ for $e_i=(U,i)$, $1\le i<M$, defined in <a href="#eq:local-predicate" data-reference-type="eqref" data-reference="eq:local-predicate">[eq:local-predicate]</a>, with $y_n(t)=x+t2^{-n}$. For every fixed $t\in[1,2]$, $$\mathbb P\left( Q_i(y_n(t))=0 \text{ for all }1\le i<M,\ n\in W_{e_i} \,\middle\|\,\xi \right) =(1-p/2)^{(M-1)r}. \label{eq:fixed-scale-miss}$$
  - Explanation: Distinct selector and terminal addresses give the exact conditional failure probability at a fixed scale.
- **C7** (bound, [source](#stmt-lem-representatives)): Fix a stable center $x$ and an atom $\xi$ of the full center exposure $\mathcal F_x$ in <a href="#eq:center-exposure" data-reference-type="eqref" data-reference="eq:center-exposure">[eq:center-exposure]</a> on which the first-default node $U$ exists. Let $h$ be its height, put $r=r_h$, and write $$e_i=(U,i),\qquad b_i^*=b_{e_i}^*,\qquad 1\le i<M.$$ There is a finite set $\mathcal R(x,U)\subset[1,2]$, depending only on $x,U$ and the deterministic windows, with $$\|\mathcal R(x,U)\|\le20Mr\bigl(1+2^{2r+2}\bigr), \label{eq:representative-count}$$ such that the following holds for the local predicates $Q_i$ in <a href="#eq:local-predicate" data-reference-type="eqref" data-reference="eq:local-predicate">[eq:local-predicate]</a>, for every realization of the tables consistent with $\xi$. For each $t\in[1,2]$, some $t'\in\mathcal R(x,U)$ satisfies $$Q_i(x+t2^{-n})=Q_i(x+t'2^{-n}) \quad\text{for all }1\le i<M\text{ and }n\in W_{e_i}. \label{eq:representative-agreement}$$
  - Explanation: Grid crossings and interval midpoints represent every local predicate configuration across normalized scales.
- **C8** (bound, [source](#stmt-prop-raw-failure)): For every fixed stable center $x$, $$\mathbb P\bigl(\exists t\in[1,2]\ \forall n\in\mathcal N: x+t2^{-n}\notin B\bigr)\le2p. \label{eq:raw-failure}$$
  - Explanation: Conditioning on the first default and taking a finite union bound controls failure over all normalized scales.

## 2. Definitions, validity and bounds

- **Affine copy** ([source](#sec:introduction)): For a set $A\subseteq\mathbb R$, a *nontrivial affine copy* of $A$ is a set $$x+sA=\{x+sa:a\in A\},\qquad x\in\mathbb R,\quad s\in\mathbb R\setminus\{0\}.$$
- **Measure universality** ([source](#sec:introduction)): The set $A$ is *measure universal* if every Lebesgue-measurable subset of $\mathbb R$ of positive measure contains such a copy.
- **Dyadic sequence** ([source](#sec:introduction)): We consider the single sequence $$D=\{2^{-n}:n\in\mathbb N,\ n\ge1\}.$$
- **Periodic density** ([source](#sec:periodic)): For a measurable $1$-periodic set $A\subseteq\mathbb R$, write $$\rho(A)=m(A\cap[0,1])$$ for its density in one period.
- **Periodic cell key** ([source](#eq:grid-nesting)): For every nonnegative integer $b$, define the periodic cell key $$J_b(z)=\left\lfloor2^{b+2}\{z\}\right\rfloor, \qquad \{z\}=z-\lfloor z\rfloor. \label{eq:grid-key}$$
- **Stable center** ([source](#eq:stable-definition)): Call $x$ *stable* if, for every such window, $$(x,x+\delta_e]\cap\Gamma_{b'}=\varnothing. \label{eq:stable-definition}$$
- **Center exposure** ([source](#eq:center-exposure)): For a fixed center $x\in\mathbb R$, expose one entry from every selector table, including those in subtrees not visited by its path. The resulting sigma-field is $$\label{eq:center-exposure} \mathcal F_x = \sigma\left( S_e\bigl(J_{b_e}(x)\bigr): e=(P,i),\ i<M \right) \subseteq\mathcal S.$$
- **Local predicate** ([source](#eq:local-predicate)): Define the local predicate $$\label{eq:local-predicate} Q_i(z)= S_{e_i}\bigl(J_{b_{e_i}}(z)\bigr)\, T_{L_i(z)}\bigl(J_{b(L_i(z))}(z)\bigr).$$

## 4. Engineering Triptych

### Panel 1 - epistemic contract

- **I-GRID**: Periodic cell keys use half-open cells and agree under coarsening of nested dyadic grids.
- **I-MAIN**: A fixed compact subset of the unit interval avoids every signed nontrivial affine copy of the dyadic sequence while retaining the stated near-full measure.

### Panel 2 - negative knowledge

- **A-SCOPE**: Apply the theorem to arbitrary infinite sequences. -> The source supplies avoidance for the dyadic sequence only.
- **A-TAIL**: Replace the infinite dyadic sequence by a finite truncation. -> The exceptional-center repair may require indices from the full tail.
- **A-INDEPENDENCE**: Multiply failure probabilities before checking terminal addresses. -> Adaptive routing does not itself establish distinct independent terminal entries.

### Panel 3 - reference implementation and oracle

Applicability: `constructive`. The deterministic periodic cell key is a finite constructive component. This code checks its nested-grid identity on rational inputs; it does not construct the compact avoiding set or certify the probabilistic and exceptional-center arguments.

```python
# INPUTS: JSON list of [numerator, denominator, b, B] integer records.
# PRECONDITIONS: denominator positive; 0 <= b <= B; finite input list.
# OUTPUTS: JSON list of [J_b, J_B, coarsened J_B] integer records.
# TIME: linear in records, with exact integer arithmetic cost depending on bit length.
# SPACE: linear in records plus integer bit storage.
# ARITHMETIC: python-flint fmpz integers; exact Euclidean division; no floating point.
# FAILURE: invalid records raise ValueError; allocation failure terminates execution.
import json, sys
from flint import fmpz
records = json.load(sys.stdin)
result = []
for a, q, b, B in records:
    if not all(type(v) is int for v in (a, q, b, B)) or q <= 0 or not 0 <= b <= B:
        raise ValueError("invalid rational grid record")
    numerator, denominator = fmpz(a), fmpz(q)
    residue = numerator - (numerator // denominator) * denominator
    coarse = int((residue * (fmpz(2) ** (b + 2))) // denominator)
    fine = int((residue * (fmpz(2) ** (B + 2))) // denominator)
    nested = fine // (2 ** (B - b))
    result.append([coarse, fine, nested])
print(json.dumps(result, separators=(",", ":")))
```

> ## Scope
>
> The formalization proves the dyadic case of the Erdős similarity conjecture. For every $0<\eta<1$, it constructs a compact set $E\subset[0,1]$ of measure greater than $1-\eta$ that contains no affine copy of $\{2^{-n}:n\ge1\}$. Explicitly, for every translation $x$ and every nonzero real dilation $s$, some point $x+s2^{-n}$ lies outside $E$. Both signs of $s$ are included.

## 7. Complete mathematical paper


We construct a compact subset of the unit interval, of measure arbitrarily close to one, that contains no affine copy of the dyadic sequence $`\{2^{-n}:n\ge1\}`$. The conclusion holds for every translation and every nonzero real dilation, of either sign, proving the dyadic case of the Erdős similarity conjecture.

<a id="sec:introduction"></a>
### Introduction

Let $m$ denote Lebesgue measure on $\mathbb R$. For a set $A\subseteq\mathbb R$, a *nontrivial affine copy* of $A$ is a set $$x+sA=\{x+sa:a\in A\},\qquad x\in\mathbb R,\quad s\in\mathbb R\setminus\{0\}.$$ The set $A$ is *measure universal* if every Lebesgue-measurable subset of $\mathbb R$ of positive measure contains such a copy. The Erdős similarity conjecture asserts that no infinite subset of $\mathbb R$ is measure universal; the problem was posed by Erdős in (Erdős 1974, Problem 4.33.7\*) <a id="pm-cite-1"></a>[[Erdos1974Problems](#ref-Erdos1974Problems)]. Every nonempty finite pattern $F$ is measure universal. Indeed, if a measurable set contains a subset $E_0$ of finite positive measure, translation continuity in $L^1$ gives $m(\bigcap_{a\in F}(E_0-sa))\to m(E_0)>0$ as $s\to0$. A point in this intersection supplies an affine copy of $F$. The difficulty therefore lies in keeping infinitely many points in the same positive-measure set. We consider the single sequence $$D=\{2^{-n}:n\in\mathbb N,\ n\ge1\}.$$

<a id="stmt-thm-main"></a>
<div id="thm:main" class="theorem">

**Theorem 1**. *For every $\eta\in(0,1)$, there is a compact set $E_\eta\subseteq[0,1]$ with $m(E_\eta)>1-\eta$ such that $$\text{for every }x\in\mathbb R\text{ and every }s\in\mathbb R\setminus\{0\},
 \quad x+sD\nsubseteq E_\eta.$$ Equivalently, for every such $x,s$ there is an integer $n\ge1$ with $x+s2^{-n}\notin E_\eta$.*

</div>

Thus the dyadic sequence is not measure universal. The theorem concerns one infinite pattern and all of its signed affine copies; the conjecture for arbitrary infinite sets is not addressed. Compactness and the near-full-measure conclusion follow directly from the open sets used in the construction.

<a id="pm-h-3"></a>
#### Related results

Classical results concern slowly decreasing sequences. Falconer (Falconer 1984) <a id="pm-cite-2"></a>[[Falconer1984](#ref-Falconer1984)] and Eigen (Eigen 1985) <a id="pm-cite-3"></a>[[Eigen1985](#ref-Eigen1985)] proved nonuniversality for positive sequences $a_n\downarrow0$ with $a_{n+1}/a_n\to1$; see also the proof in (Humke and Laczkovich 1998, Corollary 1) <a id="pm-cite-4"></a>[[HumkeLaczkovich1998](#ref-HumkeLaczkovich1998)]. Humke and Laczkovich give a finite hitting-set characterization and further relative-gap criteria (Humke and Laczkovich 1998, Theorems 1–2) <a id="pm-cite-5"></a>[[HumkeLaczkovich1998](#ref-HumkeLaczkovich1998)]. Kolountzakis’s finite-gap criterion uses arbitrarily large finite subsets of a positive sequence: the minimum gaps, divided by their largest points, must have negative logarithms growing sublinearly in the cardinalities (Kolountzakis 1997, Theorem 3) <a id="pm-cite-6"></a>[[Kolountzakis1997](#ref-Kolountzakis1997)]. Chlebík gives a translation-invariant formulation normalized by the diameter (Chlebík 2015, Theorem 15) <a id="pm-cite-7"></a>[[Chlebik2015](#ref-Chlebik2015)]. Dyadic subsets do not satisfy either condition: for $n\ge2$ dyadic points $a_1>\cdots>a_n$, the minimum gap is at most $a_{n-1}\le2^{-(n-2)}a_1$, whereas the diameter $a_1-a_n$ is at least $a_1/2$. Either normalized minimum gap is therefore at most $2^{-(n-3)}$.

Additive structure gives another family of results. Bourgain proved that a sum of three infinite sets is nonuniversal (Bourgain 1987) <a id="pm-cite-8"></a>[[Bourgain1987](#ref-Bourgain1987)], and Kolountzakis treated sums of two copies of certain sequences, including $D+D$ (Kolountzakis 1997, sec. 3.4) <a id="pm-cite-9"></a>[[Kolountzakis1997](#ref-Kolountzakis1997)]. The distinction between the dyadic sequence and larger patterns is important. Mora Cuéllar, Iosevich, Kulkarni, Rojas Aravena and Yavicoli prove nonuniversality for the sum or difference of a nonconstant geometric sequence tending to zero and an arbitrary infinite set (Mora Cuellar et al. 2026, Theorem 2) <a id="pm-cite-10"></a>[[MoraCuellarEtAl2026Twofold](#ref-MoraCuellarEtAl2026Twofold)]. Their Introduction explicitly separates the single dyadic sequence from this two-fold sumset result. Avoiding a larger pattern does not imply avoidance of a subset of that pattern.

Iosevich, Kulkarni, Mora Cuéllar, Rojas Aravena and Yavicoli prove a nonuniversality criterion for sets supporting a Rajchman probability measure, that is, a probability measure whose Fourier transform tends to zero at infinity (Iosevich et al. 2026, Theorem 1.5) <a id="pm-cite-11"></a>[[IKMRY2026Rajchman](#ref-IKMRY2026Rajchman)]. A countable set cannot support such a measure (Iosevich et al. 2026, Proposition 4.1) <a id="pm-cite-12"></a>[[IKMRY2026Rajchman](#ref-IKMRY2026Rajchman)], so that criterion does not apply to $D$. Their more general uniform-density criterion on the circle (Iosevich et al. 2026, Proposition 3.2) <a id="pm-cite-13"></a>[[IKMRY2026Rajchman](#ref-IKMRY2026Rajchman)] also fails for $D\cup\{0\}$: for every integer $k\ge1$, dilation by $2^k$ leaves its image modulo one unchanged, and that image stays a distance $1/4$ from $3/4$.

Other notions of size and other transformation classes also lead to different questions. For certain sequences tending to zero, Cruz, Lai and Pramanik obtain sets of Hausdorff dimension one avoiding affine copies of the sequence together with its limit point; the avoiding sets in their construction have Lebesgue measure zero (A. D. Cruz, Lai, and Pramanik 2023, preprint, Corollary 1.2 and Proposition 4.4) <a id="pm-cite-14"></a>[[CruzLaiPramanik2023](#ref-CruzLaiPramanik2023)]. In the other direction, Feng, Lai and Xiong’s bi-Lipschitz embedding theorem applies to the dyadic sequence (Feng, Lai, and Xiong 2024, preprint, Theorem 1.1) <a id="pm-cite-15"></a>[[FengLaiXiong2024](#ref-FengLaiXiong2024)]. Such nonlinear embeddings are compatible with the affine nonuniversality in Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a>. A separate earlier preprint of Cruz, Lai and Pramanik claiming the full similarity conjecture was withdrawn because of a gap in its Proposition 3.3 (A. Cruz, Lai, and Pramanik 2020) <a id="pm-cite-16"></a>[[CruzLaiPramanik2020Withdrawn](#ref-CruzLaiPramanik2020Withdrawn)].

<a id="pm-h-4"></a>
#### The construction

Our main step is to construct an open, $1$-periodic set of small density that meets every $x+tD$ with $x\in\mathbb R$ and $t\in[1,2]$. The next section states this intermediate result precisely. Dyadic rescaling and reflection then produce a small open set meeting every signed affine copy of $D$; its complement in $[0,1]$ is the desired compact set. Periodic blocking sets and summable measure budgets also appear in (Iosevich et al. 2026, Lemma 3.1 and Proposition 3.2) <a id="pm-cite-17"></a>[[IKMRY2026Rajchman](#ref-IKMRY2026Rajchman)]; the finite construction below supplies the required hitting property for $D$.

Random cell constructions, discretization of the dilation parameter at a fixed center, and integration over centers occur in Kolountzakis (Kolountzakis 1997, sec. 3.2) <a id="pm-cite-18"></a>[[Kolountzakis1997](#ref-Kolountzakis1997)], Chlebík (Chlebík 2015, sec. 5) <a id="pm-cite-19"></a>[[Chlebik2015](#ref-Chlebik2015)], and Kolountzakis–Papageorgiou (Kolountzakis and Papageorgiou 2025, sec. 3.1) <a id="pm-cite-20"></a>[[KolountzakisPapageorgiou2025](#ref-KolountzakisPapageorgiou2025)]. Exceptional centers are repaired by an open cover in Kolountzakis (Kolountzakis 1997, sec. 2.2 and 3.2) <a id="pm-cite-21"></a>[[Kolountzakis1997](#ref-Kolountzakis1997)]; Chlebík also describes adding the centers themselves when the pattern contains zero (Chlebík 2015, sec. 3, final remark) <a id="pm-cite-22"></a>[[Chlebik2015](#ref-Chlebik2015)]. We use the open-neighborhood form, since $0$ is a limit point of $D$ but is not in $D$. An earlier attempt to extend the random-cell approach to the dyadic sequence is described by Solymosi (Solymosi 2011, sec. 3) <a id="pm-cite-23"></a>[[Solymosi2011Sparse](#ref-Solymosi2011Sparse)]; that report does not claim a completed construction. The argument below implements these principles with separated index windows and a finite routing construction. All estimates needed for the proof are supplied here.

To construct the periodic set, we first assign each point of the line to one leaf of a finite ordered tree with $M$ children at each internal node and $d$ levels. Independent fair binary tables, evaluated on dyadic cells, determine the route. At each node, the first successful test chooses a child; if all tests fail, the last child is chosen by default. Each leaf carries a second table whose entries select points with a small prescribed probability $p$. This keeps the expected density small.

At a node, the default child is chosen only when all $M-1$ tested bits vanish. Although this is rare for large $M$, taking the depth $d$ sufficiently large makes a default somewhere along the center’s route likely. At the first such node, all nondefault choices have been rejected by the center. Carefully chosen dyadic translates preserve the route to that node and its earlier rejections, but consult fresh entries at their current-window resolution. Many nondefault children and many translates then supply many potential hits.

Two features make those tests useful simultaneously for every normalized scale. First, an interval of dyadic indices is assigned to each edge, in the order in which the tree is traversed. Gaps between these intervals preserve the earlier routing decisions for all but a small set of centers. Second, each interval is long enough to control every cell resolution in its child subtree. This bounds the number of different local tests as the scale varies. We expose the tables in stages, proving that the terminal entries used by these adaptively chosen routes are distinct before multiplying their failure probabilities. A finite union bound then controls all scales in $[1,2]$.

The resulting set may still miss copies centered in a small closed set. An open neighborhood of those centers repairs every such copy, since $x+t2^{-n}$ converges to $x$. This last step is what changes an estimate on exceptional centers into a statement valid at every center.

The windows and their spatial stability are constructed in Section <a href="#sec:windows" data-reference-type="ref" data-reference="sec:windows">3</a>. Section <a href="#sec:routing" data-reference-type="ref" data-reference="sec:routing">4</a> defines the random set and proves the independent-trial estimate. Section <a href="#sec:scales" data-reference-type="ref" data-reference="sec:scales">5</a> handles the continuum of normalized scales and removes the exceptional centers. Section <a href="#sec:global" data-reference-type="ref" data-reference="sec:global">6</a> completes the signed-scale deduction of Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a>.

<a id="sec:periodic"></a>
### The periodic hitting problem

For a measurable $1$-periodic set $A\subseteq\mathbb R$, write $$\rho(A)=m(A\cap[0,1])$$ for its density in one period. We will sometimes identify such a set with its image in the circle $\mathbb T=\mathbb R/\mathbb Z$, equipped with normalized Lebesgue measure. This identification preserves the density. Open or closed subsets of the circle lift to open or closed periodic subsets of $\mathbb R$.

<a id="stmt-lem-periodic"></a>
<div id="lem:periodic" class="lemma">

**Lemma 2** (Periodic hitting sets). *For every $p\in(0,1)$, there exists an open $1$-periodic set $H\subseteq\mathbb R$ such that $\rho(H)\le6p$ and $$\forall x\in\mathbb R\ \forall t\in[1,2]\ \exists n\in\mathbb Z_{\ge1}:
 \qquad x+t2^{-n}\in H.$$*

</div>

The same set $H$ works for every center and every scale in the displayed interval. The witness $n$ may depend on both. In Section <a href="#sec:global" data-reference-type="ref" data-reference="sec:global">6</a>, we apply the lemma with a summable sequence of parameters, rescale the resulting periodic sets by powers of two, and include their reflections. This handles every nonzero real scale while keeping the total measure removed from $[0,1]$ small.

For the proof of Lemma <a href="#lem:periodic" data-reference-type="ref" data-reference="lem:periodic">2</a>, fix $p\in(0,1)$. We construct a random periodic set $B$ with expected density $p$, together with a finite set $\mathcal N$ of positive integer indices. Outside a deterministic set of centers of density less than $p$, the probability that some $t\in[1,2]$ avoids $B$ at all indices in $\mathcal N$ will be at most $2p$. We then enlarge $B$ to an open set, bound the expected measure of its exceptional centers, and cover those centers by a small open set. The last step uses further indices in the dyadic tail; $\mathcal N$ need not provide the hits at the repaired centers.

<a id="sec:windows"></a>
### Separated index windows

We first assign a finite block of dyadic indices to every edge of an ordered tree. Gaps between the blocks will let small translations preserve earlier grid cells. Each block will also be long enough to control all resolutions needed below its child. These two properties will serve different purposes in the random construction.

<a id="pm-h-7"></a>
#### The tree and the window lengths

<a id="eq:tree-parameters"></a>
Fix $p\in(0,1)$. Choose integers $M\ge2$ and $d\ge1$ such that $$\frac{p(M-1)}2\ge10,
 \qquad
 (1-2^{1-M})^d<p.
 \label{eq:tree-parameters}$$ Such choices can be made in this order: the first inequality holds for large enough $M$, after which $0<1-2^{1-M}<1$ permits the second choice. Let $\mathcal T$ be the complete ordered tree of height $d$ in which each internal vertex has $M$ children. Its root has height $d$, its leaves have height $0$, and the children of an internal vertex $P$ are $P_1,\ldots,P_M$. Write $e=(P,i)$ for the edge from $P$ to $P_i$. The finite total number of edges is $$K=\sum_{\ell=1}^d M^\ell.$$ List the edges in the following preorder: for each vertex $P$, list $(P,1)$ and all edges below $P_1$, then $(P,2)$ and all edges below $P_2$, and so on. Thus an edge together with all edges below its child forms one consecutive block in the list.

Choose an integer $g\ge1$ such that <a id="eq:gap-budget"></a>$$K2^{2-g}<p.
 \label{eq:gap-budget}$$ This choice depends only on the already fixed tree. We will leave $g$ unused indices between consecutive windows.

The $M-1$ nondefault child windows of a node, each of length $r$, will together supply $(M-1)r$ random tests at a fixed scale $t\in[1,2]$. The exponential factor in the next inequality will bound the probability that all these tests fail. The preceding factor will bound the size of a finite list of scale values that represents every possible collection of local grid keys as $t$ varies. Making their product small will control all normalized scales by a finite union bound; Sections <a href="#sec:routing" data-reference-type="ref" data-reference="sec:routing">4</a> and <a href="#sec:scales" data-reference-type="ref" data-reference="sec:scales">5</a> prove these two bounds.

<a id="eq:entropy-budget"></a>
Choose an integer $r_*\ge1$ such that, for every integer $r\ge r_*$, $$20Mr(1+2^{2r+2})
       \exp\!\left(-\frac{p(M-1)}2r\right)<p.
 \label{eq:entropy-budget}$$ For completeness, the left side is at most $100M e^{-7r}$ when $r\ge1$: use <a href="#eq:tree-parameters" data-reference-type="eqref" data-reference="eq:tree-parameters">[eq:tree-parameters]</a>, $1+2^{2r+2}\le5e^{2r}$, and $r\le e^r$. Hence any integer $r_*>\log(100M/p)/7$ works simultaneously for all larger $r$. The uniformity will allow us to enlarge windows as needed.

<a id="eq:window-recursion"></a>
We assign a window length $r_h$ to edges whose parent has height $h$. At the same time we compute the span $\sigma_h$ of all windows in a subtree of height $h$, including the gaps between them. Starting with $\sigma_0=0$, define successively for $h=1,\ldots,d$ $$\begin{split}
 r_h&=\max\{r_*,g+\sigma_{h-1}\},\\
 \sigma_h&=
 \begin{cases}
 Mr_1+(M-1)g,&h=1,\\
 M(r_h+g+\sigma_{h-1})+(M-1)g,&h\ge2.
 \end{cases}
 \end{split}
 \label{eq:window-recursion}$$ This is a finite bottom-up recursion: $r_h$ depends only on lengths already chosen below height $h$. In particular, the choice of $g$ did not depend on the sizes of these lengths.

Now place the actual integer windows in the edge preorder, starting at $3$. An edge $e$ from height $h$ receives $W_e=\{a_e,\ldots,b_e\}$ with $b_e=a_e+r_h-1$; if $f$ immediately precedes $e$, set $a_e=b_f+g+1$. Put $$\mathcal N=\bigcup_{e\in\mathcal T}W_e,$$ where the union is over the edges of the tree. The span interpretation of <a href="#eq:window-recursion" data-reference-type="eqref" data-reference="eq:window-recursion">[eq:window-recursion]</a> follows by induction. At height $1$ there are $M$ windows and $M-1$ gaps. At height $h\ge2$, each child block consists of an incoming window of length $r_h$, one gap, and a subtree block of span $\sigma_{h-1}$; there are another $M-1$ gaps between these child blocks.

<a id="eq:padding"></a>
For an edge $e=(P,i)$, let $b_e^*$ be the largest window endpoint among $e$ and all edges below $P_i$. If $P$ has height $h=1$, this block consists only of $e$, and its span is $r_1$. If $h\ge2$, its span is $r_h+g+\sigma_{h-1}$. Therefore in both cases $$b_e^*-a_e+1\le r_h+g+\sigma_{h-1}\le2r_h.
 \label{eq:padding}$$ In particular, <a href="#eq:entropy-budget" data-reference-type="eqref" data-reference="eq:entropy-budget">[eq:entropy-budget]</a> applies to every length $r_h$, while <a href="#eq:padding" data-reference-type="eqref" data-reference="eq:padding">[eq:padding]</a> bounds a whole child block in terms of its incoming window. All edges, including those with child index $M$, receive windows under this construction.

The padding bound has a specific purpose: the range of window indices from $a_e$ through $b_e^*$ in a child block is controlled by the length of its incoming window. The gaps have a different role, established next: for most centers, translations indexed by a later window preserve the earlier cells used in the routing decisions. These are the two deterministic inputs to the routing and scale-counting arguments.

<a id="pm-h-8"></a>
#### Earlier grid cells remain unchanged

<a id="eq:grid-nesting"></a>
For every nonnegative integer $b$, define the periodic cell key <a id="eq:grid-key"></a>$$J_b(z)=\left\lfloor2^{b+2}\{z\}\right\rfloor,
 \qquad \{z\}=z-\lfloor z\rfloor.
 \label{eq:grid-key}$$ Its boundaries on the real line form the lattice $\Gamma_b=2^{-(b+2)}\mathbb Z$. In particular, every integer is a boundary. Cells are half-open on the right, so a boundary belongs to the cell starting there. The grids are nested: for $B\ge b$, $$J_b(z)=\left\lfloor\frac{J_B(z)}{2^{B-b}}\right\rfloor.
 \label{eq:grid-nesting}$$ This follows by writing $2^{B+2}\{z\}=J_B(z)+\varepsilon$ with $0\le\varepsilon<1$ and dividing by the integer $2^{B-b}$.

<a id="eq:stable-definition"></a>
We seek centers for which translations indexed by one window preserve every earlier grid key. For a noninitial window $W_e$, let $b'$ be the endpoint of the immediately preceding window, and put $\delta_e=2^{1-a_e}$. Call $x$ *stable* if, for every such window, $$(x,x+\delta_e]\cap\Gamma_{b'}=\varnothing.
 \label{eq:stable-definition}$$ Let $G$ denote the set of stable centers. The intervals in <a href="#eq:stable-definition" data-reference-type="eqref" data-reference="eq:stable-definition">[eq:stable-definition]</a> are taken on the real line, so crossings of an integer are included without a separate convention on the circle.

<a id="stmt-lem-stable"></a>
<div id="lem:stable" class="lemma">

<a id="eq:stable-keys"></a>
**Lemma 3**. *The set $G$ is measurable and $1$-periodic, and $\rho(G^c)<p$. For every $x\in G$, every window $W_e$, every $n\in W_e$, every $t\in[1,2]$, and every window $W_f$ earlier than $W_e$, $$J_{b_f}(x+t2^{-n})=J_{b_f}(x).
 \label{eq:stable-keys}$$ These assertions include centers lying on grid boundaries.*

</div>

<details id="proof-stmt-lem-stable"><summary>Proof of stmt-lem-stable</summary>

*Proof.* For a fixed noninitial window, the centers violating <a href="#eq:stable-definition" data-reference-type="eqref" data-reference="eq:stable-definition">[eq:stable-definition]</a> are exactly $$E_e=\bigcup_{\beta\in\Gamma_{b'}}[\beta-\delta_e,\beta),$$ because $\beta\in(x,x+\delta_e]$ if and only if $\beta-\delta_e\le x<\beta$. This is a measurable periodic set. Since $a_e=b'+g+1$, $$2^{b'+2}\delta_e=2^{2-g}<p/K<1.$$ Thus these intervals have disjoint interiors modulo one. There are $2^{b'+2}$ of them per period, each of length $\delta_e$, and hence $\rho(E_e)=2^{2-g}$. The complement of $G$ is the union of these sets over the $K-1$ noninitial windows. Consequently $$\rho(G^c)\le(K-1)2^{2-g}<p.$$ This also proves measurability and periodicity of $G$.

Now fix the data in <a href="#eq:stable-keys" data-reference-type="eqref" data-reference="eq:stable-keys">[eq:stable-keys]</a>. If $W_e$ is the first window, there is no earlier $W_f$. Otherwise $0<t2^{-n}\le2^{1-a_e}=\delta_e$, so stability implies that the interval $(x,x+t2^{-n}]$ contains no boundary of $\Gamma_{b'}$. Both endpoints therefore have the same $J_{b'}$ key. This remains true when $x$ itself is a boundary, since it belongs to the cell on its right; landing on a boundary at a positive displacement has been excluded. An integer cannot lie in this interval either, so passing to periodic keys introduces no additional case. Finally, every earlier window satisfies $b_f\le b'$, and <a href="#eq:grid-nesting" data-reference-type="eqref" data-reference="eq:grid-nesting">[eq:grid-nesting]</a> gives <a href="#eq:stable-keys" data-reference-type="eqref" data-reference="eq:stable-keys">[eq:stable-keys]</a>. ◻

</details>

The tree, all windows, and $G$ are now fixed before any random choices. The key agreement concerns earlier windows only. This is the property that will preserve the required earlier decisions while allowing tests at the current window’s finer resolution.

<a id="sec:routing"></a>
### Random routing and independent tests

We now use the windows from the preceding section to construct a random periodic set $B$ of expected density $p$. Selectors send each spatial point to one leaf of the tree, where an independent terminal entry decides membership in $B$. For a stable center, the first default choice on its path will provide several child windows in which to test nearby points.

<a id="pm-h-10"></a>
#### The tables and the selected set

For each edge $e=(P,i)$ with $i<M$, let $$S_e:\{0,\ldots,2^{b_e+2}-1\}\longrightarrow\{0,1\}$$ be a random table whose entries are independent Bernoulli variables with parameter $1/2$. There is no selector table for the default edge $(P,M)$. For a leaf $L$, let $b(L)$ be the endpoint of the window assigned to its unique incoming edge, and let $$T_L:\{0,\ldots,2^{b(L)+2}-1\}\longrightarrow\{0,1\}$$ be a random table whose entries are independent Bernoulli variables with parameter $p$. All entries of all selector and terminal tables are mutually independent. The tree and every table are finite, so these variables define a finite product probability space $\Omega$. We write $\mathbb P$ and $\mathbb E$ for its probability and expectation.

<a id="eq:random-set"></a>
Given the tables and a point $z\in\mathbb R$, start at the root. At an internal node $P$, choose the first child $P_i$, $i<M$, for which $$S_{(P,i)}\bigl(J_{b_{(P,i)}}(z)\bigr)=1.$$ If all $M-1$ values are zero, choose the default child $P_M$. Continue until reaching a leaf, denoted by $L(z)$, and define $$\label{eq:random-set}
 B=\left\{z\in\mathbb R:
 T_{L(z)}\bigl(J_{b(L(z))}(z)\bigr)=1\right\}.$$ The table rules use only periodic keys. Since all grids in the construction are nested, membership in $B$ is constant on each cell of the finest grid used. Thus every realization of $B$ is a $1$-periodic measurable set, consisting of finitely many half-open cells per period.

<a id="eq:mean-density"></a>
Let $\mathcal S$ be the sigma-field generated by every entry of every selector table. For fixed $z$, conditioning on $\mathcal S$ fixes $L(z)$ and the key of its terminal entry. That entry still has probability $p$ of being one, since terminal tables are independent of all selectors. Hence $$\mathbb P(z\in B\mid\mathcal S)=p.$$ Integrating over one period and interchanging the integral with the finite weighted sum over $\Omega$ gives $$\label{eq:mean-density}
 \mathbb E\rho(B)=\int_0^1\mathbb P(z\in B)\,dz=p.$$

<a id="pm-h-11"></a>
#### Conditioning at a center

<a id="eq:center-exposure"></a>
For a fixed center $x\in\mathbb R$, expose one entry from every selector table, including those in subtrees not visited by its path. The resulting sigma-field is $$\label{eq:center-exposure}
 \mathcal F_x
 =
 \sigma\left(
 S_e\bigl(J_{b_e}(x)\bigr):
 e=(P,i),\ i<M
 \right)
 \subseteq\mathcal S.$$ An atom $\xi$ of $\mathcal F_x$ means the event specifying all these exposed values; we write $\mathbb P(\,\cdot\mid\xi)$ for conditioning on that event. Every such atom has positive probability. The exposed addresses $(e,J_{b_e}(x))$ are deterministic once $x$ is fixed, with the table name $e$ included in the address. Consequently, on each atom, all remaining selector entries retain their independent fair law, and all terminal entries retain their independent Bernoulli-$p$ law.

The exposed values determine the full path of $x$. When that path chooses a default child, let $U$ denote its first internal node at which this happens. Thus the existence and identity of $U$ are determined by $\mathcal F_x$. The next estimate concerns the original product law, before an atom of $\mathcal F_x$ is fixed.

<a id="stmt-lem-first-default"></a>
<div id="lem:first-default" class="lemma">

**Lemma 4** (A default choice on the center path). *For every fixed $x\in\mathbb R$, $$\mathbb P\bigl(\text{the path of \(x\) never chooses child \(M\)}\bigr)
 =
 (1-2^{1-M})^d<p.$$*

</div>

<details id="proof-stmt-lem-first-default"><summary>Proof of stmt-lem-first-default</summary>

*Proof.* At any internal node, the default child is chosen exactly when its $M-1$ selector entries at $x$ are all zero. This has probability $2^{-(M-1)}=2^{1-M}$.

To compute the probability along the path, reveal the entries at an internal node only when the path first reaches it. The decisions leading to that node use tables at its strict ancestors. Its own tables are distinct from all of those tables and have not yet been revealed, so their entries at $x$ remain independent fair bits, conditional on the preceding path history. At each of the $d$ internal-node decisions, the conditional probability of a non-default choice is therefore $1-2^{1-M}$. Iterating this conditional probability gives $(1-2^{1-M})^d$. The strict inequality is the choice of $d$ in <a href="#eq:tree-parameters" data-reference-type="eqref" data-reference="eq:tree-parameters">[eq:tree-parameters]</a>. ◻

</details>

<a id="pm-h-12"></a>
#### Routing trials through the first default

Fix henceforth a stable center $x\in G$, and condition on an atom $\xi$ of $\mathcal F_x$ for which $U$ exists. The node $U$ is fixed under this conditioning. Let $h$ be its height, and write $$r=r_h,\qquad e_i=(U,i),\qquad b_i^*=b_{e_i}^*
 \quad(1\le i<M),\qquad y_n(t)=x+t2^{-n}.$$ At $U$, all the exposed non-default selector values are zero.

<a id="eq:local-predicate"></a>
For $i<M$ and $z\in\mathbb R$, let $L_i(z)$ be the leaf obtained by applying the same path rule starting at the child $U_i$. If $U_i$ is already a leaf, set $L_i(z)=U_i$. Define the local predicate $$\label{eq:local-predicate}
 Q_i(z)=
 S_{e_i}\bigl(J_{b_{e_i}}(z)\bigr)\,
 T_{L_i(z)}\bigl(J_{b(L_i(z))}(z)\bigr).$$ The function $Q_i$ takes values in $\{0,1\}$ and consults only the selector on $e_i$ and tables in the subtree rooted at $U_i$. It provides a sufficient condition for membership in $B$ at the points indexed by $W_{e_i}$.

<a id="stmt-lem-routing"></a>
<div id="lem:routing" class="lemma">

**Lemma 5** (Preservation of the route). *For every outcome in $\xi$, every $i<M$, every $n\in W_{e_i}$, and every $t\in[1,2]$, the actual root path of $y_n(t)$ reaches $U$ and rejects children $1,\ldots,i-1$ there. In particular, <a id="eq:local-hit"></a>$$\label{eq:local-hit}
 Q_i(y_n(t))=1
 \quad\Longrightarrow\quad y_n(t)\in B.$$*

</div>

<details id="proof-stmt-lem-routing"><summary>Proof of stmt-lem-routing</summary>

*Proof.* Consider a strict ancestor $P$ of $U$, and let $P_a$ be its child on the path of $x$ to $U$. Since $U$ is the first default node, $a<M$. The decision at $P$ uses precisely the zero values of the selectors $1,\ldots,a-1$ and the value one of selector $a$. Each of the edges $(P,j)$, $j\le a$, precedes every edge in the subtree of $P_a$ in the prescribed preorder. Their windows therefore precede $W_{e_i}$. By the stable-key identity <a href="#eq:stable-keys" data-reference-type="eqref" data-reference="eq:stable-keys">[eq:stable-keys]</a>, each of these selector evaluations at $y_n(t)$ agrees with its evaluation at $x$. Induction from the root along the ancestor chain shows that $y_n(t)$ makes the same choices and reaches $U$. Later sibling selectors at an ancestor are not needed to make its choice.

For every $j<i$, the edge $(U,j)$ also precedes $e_i$. Its selector value at $x$ is zero, because $x$ takes the default child at $U$. Another application of <a href="#eq:stable-keys" data-reference-type="eqref" data-reference="eq:stable-keys">[eq:stable-keys]</a> makes the corresponding value at $y_n(t)$ zero. Thus the actual path rejects children $1,\ldots,i-1$ at $U$.

If $Q_i(y_n(t))=1$, the selector on $e_i$ is one, so the actual path chooses child $i$ at $U$. Its continuation is exactly the rule defining $L_i(y_n(t))$, and the terminal entry in <a href="#eq:local-predicate" data-reference-type="eqref" data-reference="eq:local-predicate">[eq:local-predicate]</a> is one. The membership rule <a href="#eq:random-set" data-reference-type="eqref" data-reference="eq:random-set">[eq:random-set]</a> now gives $y_n(t)\in B$. Figure <a href="#fig:routing" data-reference-type="ref" data-reference="fig:routing">2</a> records this common-prefix and branching argument. All equalities used here hold for every completion of the unexposed tables and every $t\in[1,2]$, as required. ◻

</details>

#### Independent terminal tests

We now estimate the probability that all the local tests fail at one fixed scale. The selected leaves may depend on the selectors. To keep that dependence explicit, we first expose all selectors, identify the terminal entries being read, and then average over the selectors.

<a id="stmt-lem-fixed-scale"></a>
<div id="lem:fixed-scale" class="lemma">

**Lemma 6** (The fixed-scale estimate). *Fix a stable center $x$ and an atom $\xi$ of the center-exposure sigma-field $\mathcal F_x$ in <a href="#eq:center-exposure" data-reference-type="eqref" data-reference="eq:center-exposure">[eq:center-exposure]</a>, on which the first default node $U$ exists. Let $h$ be its height, put $r=r_h$, and use the local predicates $Q_i$ for $e_i=(U,i)$, $1\le i<M$, defined in <a href="#eq:local-predicate" data-reference-type="eqref" data-reference="eq:local-predicate">[eq:local-predicate]</a>, with $y_n(t)=x+t2^{-n}$. For every fixed $t\in[1,2]$, <a id="eq:fixed-scale-miss"></a>$$\mathbb P\left(
 Q_i(y_n(t))=0
 \text{ for all }1\le i<M,\ n\in W_{e_i}
 \,\middle|\,\xi
 \right)
 =(1-p/2)^{(M-1)r}.
 \label{eq:fixed-scale-miss}$$*

</div>

<details id="proof-stmt-lem-fixed-scale"><summary>Proof of stmt-lem-fixed-scale</summary>

*Proof.* On the fixed atom $\xi$, the node $U$, the windows $W_{e_i}$, and the set of pairs $$\mathcal I=\{(i,n):1\le i<M,\ n\in W_{e_i}\}$$ are fixed. Its cardinality is $(M-1)r$. For these pairs define $$A_{i,n}=S_{e_i}\bigl(J_{b_{e_i}}(y_n(t))\bigr).$$ We first check that these are distinct selector entries, none of which was exposed at $x$.

Fix $i$, and abbreviate $a=a_{e_i}$ and $b=b_{e_i}$. For $n<n'$ in this window, $$y_n(t)-y_{n'}(t)
 =t\,2^{-n'}(2^{n'-n}-1)\ge 2^{-b}.$$ Also $y_n(t)-x=t2^{-n}\ge2^{-b}$. All these points lie in $[x,x+2^{1-a}]$, an interval of length at most $1/4$, since $a\ge3$. Thus the circular distance between any two of them equals their ordinary distance and is at least $2^{-b}$. Two points in the same half-open $J_b$-cell have circular distance less than $2^{-(b+2)}$. Consequently the keys of $x$ and all $y_n(t)$, $n\in W_{e_i}$, are pairwise distinct. This argument also covers a crossing of an integer and points on cell boundaries.

For different $i$, the selector tables themselves differ. The variables $A_{i,n}$ therefore read distinct coordinates outside the entire exposed coordinate set defining $\mathcal F_x$. Conditional on $\xi$, they remain independent fair bits.

Next condition on the sigma-algebra $\mathcal S$ of all selectors. For each pair, its selected local leaf $$L_{i,n}=L_i(y_n(t))$$ and its terminal address $$\kappa_{i,n}=
 \bigl(L_{i,n},J_{b(L_{i,n})}(y_n(t))\bigr)$$ are now fixed. We claim that these addresses are distinct for all pairs in $\mathcal I$. If the child indices differ, the leaves lie in disjoint child subtrees of $U$, so their terminal tables differ. If the child indices agree but the leaves differ, their tables again differ. It remains to consider two different indices $n,n'$ that select the same leaf $L$ below one child $U_i$.

For every leaf below $U_i$, its terminal resolution satisfies $b(L)\ge b_{e_i}$. If $U_i$ is a leaf, then $b(L)=b_{e_i}$. Otherwise the last edge into $L$ occurs after $e_i$ in the preorder, so its window endpoint is larger. By the nested-key identity <a href="#eq:grid-nesting" data-reference-type="eqref" data-reference="eq:grid-nesting">[eq:grid-nesting]</a>, different keys at resolution $b_{e_i}$ remain different at resolution $b(L)$, including at grid boundaries. The preceding separation of $y_n(t)$ and $y_{n'}(t)$ proves $\kappa_{i,n}\ne\kappa_{i,n'}$. This proves the claim, even for pairs with $A_{i,n}=0$.

The terminal tables are independent of $\mathcal S$. For each realization of all selectors, the addresses just identified are fixed distinct coordinates of those tables. The corresponding terminal bits $$V_{i,n}=
 T_{L_{i,n}}\bigl(J_{b(L_{i,n})}(y_n(t))\bigr)$$ therefore have the product Bernoulli $p$ law conditional on $\mathcal S$. Since $Q_i(y_n(t))=A_{i,n}V_{i,n}$, only the pairs with $A_{i,n}=1$ require a terminal bit to vanish. On $\xi$ we obtain $$\mathbb P\left(
 Q_i(y_n(t))=0\text{ for all }(i,n)\in\mathcal I
 \,\middle|\,\mathcal S
 \right)
 =(1-p)^{\sum_{(i,n)\in\mathcal I}A_{i,n}}.$$ The empty-success case has exponent zero and probability one.

Finally, $\mathcal F_x\subset\mathcal S$, so conditional expectation and the independent fair law of the $A_{i,n}$ on $\xi$ give $$\begin{aligned}
 &\mathbb P\left(
 Q_i(y_n(t))=0\text{ for all }(i,n)\in\mathcal I
 \,\middle|\,\xi
 \right)\\
 &\qquad=
 \mathbb E\left[(1-p)^{\sum_{(i,n)\in\mathcal I}A_{i,n}}
          \,\middle|\,\xi\right]\\
 &\qquad=
 \prod_{(i,n)\in\mathcal I}
 \left(\frac12+\frac12(1-p)\right)
 =(1-p/2)^{(M-1)r}.
\end{aligned}$$ ◻

</details>

The estimate applies separately to each scale fixed on the exposure atom. In the next step, the grid geometry will supply finitely many such scales, allowing a union bound over all $t\in[1,2]$.

<a id="sec:scales"></a>
### All normalized scales and all centers

The preceding estimate concerns a fixed scale. To control every $t\in[1,2]$, we track the local predicates $Q_i$ on the grids of their own child subtrees. The padding of each window bounds the number of changes in these predicates as the scale varies. The use of deterministic grid crossings to discretize scales at a fixed center follows the same principle as (Kolountzakis 1997, sec. 3.2) <a id="pm-cite-24"></a>[[Kolountzakis1997](#ref-Kolountzakis1997)] <a id="pm-cite-25"></a>[[Chlebik2015](#ref-Chlebik2015)], (Chlebík 2015, sec. 5), and (Kolountzakis and Papageorgiou 2025, sec. 3.1) <a id="pm-cite-26"></a>[[KolountzakisPapageorgiou2025](#ref-KolountzakisPapageorgiou2025)]. Here the crossings must be counted within each child subtree, so that the bound remains compatible with the conditional trial estimate.

<a id="stmt-lem-representatives"></a>
<div id="lem:representatives" class="lemma">

<a id="eq:representative-agreement"></a>
**Lemma 7**. *Fix a stable center $x$ and an atom $\xi$ of the full center exposure $\mathcal F_x$ in <a href="#eq:center-exposure" data-reference-type="eqref" data-reference="eq:center-exposure">[eq:center-exposure]</a> on which the first-default node $U$ exists. Let $h$ be its height, put $r=r_h$, and write $$e_i=(U,i),\qquad b_i^*=b_{e_i}^*,\qquad 1\le i<M.$$ There is a finite set $\mathcal R(x,U)\subset[1,2]$, depending only on $x,U$ and the deterministic windows, with <a id="eq:representative-count"></a>$$|\mathcal R(x,U)|\le20Mr\bigl(1+2^{2r+2}\bigr),
 \label{eq:representative-count}$$ such that the following holds for the local predicates $Q_i$ in <a href="#eq:local-predicate" data-reference-type="eqref" data-reference="eq:local-predicate">[eq:local-predicate]</a>, for every realization of the tables consistent with $\xi$. For each $t\in[1,2]$, some $t'\in\mathcal R(x,U)$ satisfies $$Q_i(x+t2^{-n})=Q_i(x+t'2^{-n})
 \quad\text{for all }1\le i<M\text{ and }n\in W_{e_i}.
 \label{eq:representative-agreement}$$*

</div>

<details id="proof-stmt-lem-representatives"><summary>Proof of stmt-lem-representatives</summary>

*Proof.* For fixed tables, $Q_i(z)$ is determined by $J_{b_i^*}(z)$. Indeed, its initial selector has resolution $b_{e_i}\le b_i^*$, and all selectors used to route from $U_i$ lie in that child subtree. The incoming edge of every possible terminal leaf also has endpoint at most $b_i^*$. This includes the case that $U_i$ itself is a leaf, whose terminal resolution is $b_{e_i}$, as well as leaves reached through default children. Since the grids are nested, the key $J_{b_i^*}(z)$ determines every address needed for this local predicate.

For each tested pair $(i,n)$, let $$\mathcal D_{i,n}(x)=
 \left\{2^n\bigl(j2^{-(b_i^*+2)}-x\bigr):j\in\mathbb Z\right\}
 \cap[1,2].$$ These are precisely the scales at which $x+t2^{-n}$ meets a boundary of the periodic grid $J_{b_i^*}$. The full real-line lattice in this definition also includes every passage through an integer, where the periodic key returns to its first cell.

As $t$ ranges over $[1,2]$, the point traverses a closed interval of length $2^{-n}$. Counting lattice points in that interval gives $$|\mathcal D_{i,n}(x)|\le1+2^{b_i^*+2-n}.$$ The extra one allows both endpoints to be lattice points. The subtree span bound <a href="#eq:padding" data-reference-type="eqref" data-reference="eq:padding">[eq:padding]</a> gives $b_i^*-a_{e_i}+1\le2r$; since $n\ge a_{e_i}$, $$|\mathcal D_{i,n}(x)|\le1+2^{2r+2}.$$

Take the union of these sets and the two endpoints: $$\mathcal D(x,U)=\{1,2\}\cup
 \bigcup_{1\le i<M}\ \bigcup_{n\in W_{e_i}}\mathcal D_{i,n}(x).$$ List its distinct elements as $d_1=1<\cdots<d_L=2$, and set $$\mathcal R(x,U)=\mathcal D(x,U)
 \cup\left\{\frac{d_j+d_{j+1}}2:1\le j<L\right\}.$$ There are $(M-1)r$ tested pairs, so $$\begin{aligned}
 L&\le2+(M-1)r\bigl(1+2^{2r+2}\bigr),\\
 |\mathcal R(x,U)|=2L-1
 &\le2(M-1)r\bigl(1+2^{2r+2}\bigr)+3\\
 &\le20Mr\bigl(1+2^{2r+2}\bigr).
\end{aligned}$$ On each open interval $(d_j,d_{j+1})$, every relevant grid key is constant, hence so is every tested local predicate. Its midpoint therefore represents the entire interval. Each breakpoint and each endpoint is included separately and represents its own value. This proves <a href="#eq:representative-agreement" data-reference-type="eqref" data-reference="eq:representative-agreement">[eq:representative-agreement]</a>, including the values at the boundaries of the half-open cells. ◻

</details>

The representatives use only the local predicates. A point for which $Q_i$ vanishes may take its actual route through another subtree with a finer grid. That route does not enter the count: we need only the implication from a successful local predicate to a hit of $B$.

<a id="stmt-prop-raw-failure"></a>
<div id="prop:raw-failure" class="proposition">

<a id="eq:raw-failure"></a>
**Proposition 8**. *For every fixed stable center $x$, $$\mathbb P\bigl(\exists t\in[1,2]\ \forall n\in\mathcal N:
 x+t2^{-n}\notin B\bigr)\le2p.
 \label{eq:raw-failure}$$*

</div>

<details id="proof-stmt-prop-raw-failure"><summary>Proof of stmt-prop-raw-failure</summary>

*Proof.* Condition first on an atom $\xi$ of $\mathcal F_x$ in <a href="#eq:center-exposure" data-reference-type="eqref" data-reference="eq:center-exposure">[eq:center-exposure]</a> on which the first-default node $U$ exists, and retain the notation of Lemma <a href="#lem:representatives" data-reference-type="ref" data-reference="lem:representatives">7</a>. The node $U$ and the entire set $\mathcal R(x,U)$ are fixed on this atom, before any remaining selector or terminal label is revealed. Thus Lemma <a href="#lem:fixed-scale" data-reference-type="ref" data-reference="lem:fixed-scale">6</a> applies separately to every $t'\in\mathcal R(x,U)$ and gives $$\mathbb P\bigl(Q_i(x+t'2^{-n})=0\text{ for all tested }(i,n)
       \mid\xi\bigr)
 =(1-p/2)^{(M-1)r}
 \le\exp\!\left(-\frac{p(M-1)}2r\right).$$

If some scale $t$ misses $B$ at every index in $\mathcal N$, then Lemma <a href="#lem:routing" data-reference-type="ref" data-reference="lem:routing">5</a> implies that all its tested local predicates vanish. By Lemma <a href="#lem:representatives" data-reference-type="ref" data-reference="lem:representatives">7</a>, they all vanish at one of the representative scales as well. The conditional union bound and <a href="#eq:entropy-budget" data-reference-type="eqref" data-reference="eq:entropy-budget">[eq:entropy-budget]</a> therefore give $$\begin{aligned}
 &\mathbb P\bigl(\exists t\in[1,2]\ \forall n\in\mathcal N:
 x+t2^{-n}\notin B\mid\xi\bigr)\\
 &\qquad\le
 20Mr\bigl(1+2^{2r+2}\bigr)
 \exp\!\left(-\frac{p(M-1)}2r\right)<p.
\end{aligned}$$ No independence between different representative scales is required.

This bound holds on every center-exposure atom that has a first default, since every corresponding window length is at least $r_*$. Averaging over those atoms introduces no factor for the number of possible nodes. By Lemma <a href="#lem:first-default" data-reference-type="ref" data-reference="lem:first-default">4</a>, the remaining event, on which the center’s path never chooses the default child, has probability less than $p$. Bounding failure by one on that event yields <a href="#eq:raw-failure" data-reference-type="eqref" data-reference="eq:raw-failure">[eq:raw-failure]</a>. ◻

</details>

<a id="subsec:repair"></a>
#### Removing exceptional centers

The pointwise probability bound will control the measure of the centers at which some normalized scale is missed. We first enlarge the random set to an open set, so that those exceptional centers form a closed set. A small open neighborhood of that closed set will then provide hits from the dyadic tail. This follows the open-cover completion of Kolountzakis (Kolountzakis 1997, sec. 2.2 and 3.2) <a id="pm-cite-27"></a>[[Kolountzakis1997](#ref-Kolountzakis1997)]; we give the closedness, measure and tail arguments explicitly.

<details id="proof-stmt-prop-raw-failure-2"><summary>Proof of stmt-prop-raw-failure</summary>

<a id="eq:open-mean"></a>
*Completion of the proof of Lemma <a href="#lem:periodic" data-reference-type="ref" data-reference="lem:periodic">2</a>.* The probability space $\Omega$ of all table entries is finite. For each outcome $\omega$, the set $B_\omega$ is a union of cells from one finite dyadic grid per period: its finest key determines every table lookup. Regard a periodic set as a subset of the circle $\mathbb T=\mathbb R/\mathbb Z$, with normalized Lebesgue measure equal to the density of its periodic lift. Taking the closures of the selected cells adds only finitely many endpoints. Enlarging these closed arcs by sufficiently small open circular neighborhoods therefore gives an open periodic set $B_\omega^+\supseteq B_\omega$ with <a id="eq:open-enlargement"></a>$$\rho(B_\omega^+)\le\rho(B_\omega)+p.
 \label{eq:open-enlargement}$$ For example, if the grid has $Q$ cells, enlargement by circular distance $p/(4Q)$ adds at most $p/2$ to the measure of their union. For the empty set use the empty enlargement. Since there are only finitely many outcomes, these choices introduce no measurable-selection issue. Equation <a href="#eq:mean-density" data-reference-type="eqref" data-reference="eq:mean-density">[eq:mean-density]</a> gives $$\mathbb E\rho(B_\omega^+)\le2p.
 \label{eq:open-mean}$$

<a id="eq:exceptional-centers"></a>
Define the exceptional-center set $$R_\omega=
 \left\{x\in\mathbb R:
   \exists t\in[1,2]\ \forall n\in\mathcal N,\
          x+t2^{-n}\notin B_\omega^+\right\}.
 \label{eq:exceptional-centers}$$ This set is periodic and closed. To prove closedness without any endpoint convention on a fundamental interval, let $\pi:\mathbb R\to\mathbb T$ be the quotient map and let $B_{\omega,\mathbb T}^+\subset\mathbb T$ denote the open image of $B_\omega^+$. Each map $$(\pi x,t)\longmapsto\pi(x+t2^{-n})
 \quad\hbox{from }\mathbb T\times[1,2]\hbox{ to }\mathbb T$$ is continuous. The conditions that all these images avoid $B_{\omega,\mathbb T}^+$, for $n\in\mathcal N$, consequently define a closed subset of the compact space $\mathbb T\times[1,2]$. Its projection to $\mathbb T$ is compact and hence closed. Its inverse image under $\pi$ is exactly $R_\omega$.

<a id="eq:exceptional-mean"></a>
<a id="eq:chosen-outcome"></a>
In particular, each indicator ${\bf1}_{R_\omega}(x)$ is Borel measurable in $x$. Since $\Omega$ is finite, it is also jointly measurable in $(\omega,x)$. For every stable center $x\in G$, the inclusion $B_\omega\subseteq B_\omega^+$ and Proposition <a href="#prop:raw-failure" data-reference-type="ref" data-reference="prop:raw-failure">8</a> give $$\mathbb P(x\in R_\omega)\le2p.$$ At the other centers the probability is at most $1$. Interchanging a finite sum and an integral, and using Lemma <a href="#lem:stable" data-reference-type="ref" data-reference="lem:stable">3</a>, we obtain $$\begin{aligned}
 \mathbb E\rho(R_\omega)
 &=\int_0^1\mathbb P(x\in R_\omega)\,dx \notag\\
 &\le 2p\,m(G\cap[0,1])+m(G^c\cap[0,1])
 \le2p+\rho(G^c)\le3p.
 \label{eq:exceptional-mean}
\end{aligned}$$ Thus <a href="#eq:open-mean" data-reference-type="eqref" data-reference="eq:open-mean">[eq:open-mean]</a> and <a href="#eq:exceptional-mean" data-reference-type="eqref" data-reference="eq:exceptional-mean">[eq:exceptional-mean]</a> imply $$\mathbb E\bigl(\rho(B_\omega^+)+\rho(R_\omega)\bigr)\le5p.$$ Choose one outcome whose summed density is at most this bound, and write its sets as $B^+$ and $R$. We have $$\rho(B^+)+\rho(R)\le5p.
 \label{eq:chosen-outcome}$$

It remains to cover every center in $R$. Its image $R_{\mathbb T}=\pi(R)$ is closed in the circle. If it is empty, put $V=\varnothing$. Otherwise, for $\varepsilon>0$, its open metric neighborhoods $$V_\varepsilon^{\mathbb T}
 =\{z\in\mathbb T:
           \operatorname{dist}_{\mathbb T}(z,R_{\mathbb T})
                          <\varepsilon\}$$ decrease to $R_{\mathbb T}$ as $\varepsilon\downarrow0$. Continuity of finite measure from above lets us choose $\varepsilon>0$ so that the open periodic lift $V=\pi^{-1}(V_\varepsilon^{\mathbb T})$ satisfies $$R\subseteq V,\qquad \rho(V)\le\rho(R)+p.$$ Set $H=B^+\cup V$. It is open and periodic, and <a href="#eq:chosen-outcome" data-reference-type="eqref" data-reference="eq:chosen-outcome">[eq:chosen-outcome]</a> gives $$\rho(H)\le\rho(B^+)+\rho(V)
          \le\rho(B^+)+\rho(R)+p\le6p.$$

If $x\notin R$, negating <a href="#eq:exceptional-centers" data-reference-type="eqref" data-reference="eq:exceptional-centers">[eq:exceptional-centers]</a> shows that for every $t\in[1,2]$ some $n\in\mathcal N$ satisfies $x+t2^{-n}\in B^+\subseteq H$. If $x\in R$, choose an integer $n_0\ge1$ with $2^{1-n_0}<\varepsilon$. For every $t\in[1,2]$ and every $n\ge n_0$, the circle distance satisfies $$\operatorname{dist}_{\mathbb T}
       \bigl(\pi(x+t2^{-n}),R_{\mathbb T}\bigr)
 \le \operatorname{dist}_{\mathbb T}
       \bigl(\pi(x+t2^{-n}),\pi x\bigr)
 \le t2^{-n}<\varepsilon.$$ Hence $x+t2^{-n}\in V\subseteq H$. These indices are taken from the full dyadic tail. The two cases establish the required hit for every real $x$ and every $t\in[1,2]$, completing the lemma. ◻

</details>

<a id="sec:global"></a>
### The compact avoiding set

The periodic hitting sets cover scales in $[1,2]$. We now combine their dyadic dilations, with summable densities, to cover every nonzero scale while removing arbitrarily little measure from $[0,1]$.

<details id="proof-stmt-prop-raw-failure-3"><summary>Proof of stmt-prop-raw-failure</summary>

<a id="global:normalized-hits"></a>
*Proof of Theorem <a href="#thm:main" data-reference-type="ref" data-reference="thm:main">1</a>.* Fix $\eta\in(0,1)$ and put $$p_j=\frac{\eta}{24}\,2^{-j}\qquad(j=1,2,\ldots).$$ Each $p_j$ belongs to $(0,1)$. By Lemma <a href="#lem:periodic" data-reference-type="ref" data-reference="lem:periodic">2</a>, choose an open $1$-periodic set $H_j\subset\mathbb R$ with $\rho(H_j)\le6p_j$ such that $$\label{global:normalized-hits}
 \forall y\in\mathbb R\ \forall t\in[1,2]\ \exists n\in\mathbb Z_{\ge1}:
 \qquad y+t2^{-n}\in H_j.$$ All these sets are fixed before any center or scale is chosen. Define $$C=\bigcup_{j\ge1}\bigl(2^{-j}H_j\cup(-2^{-j}H_j)\bigr),
 \qquad E=[0,1]\setminus C.$$ Dilations and reflections preserve openness, so $C$ is open. Its paired definition gives $-C=C$. Thus $E$ is a closed subset of $[0,1]$, and is compact.

For each $j$, periodicity and a change of variables give the exact identities $$\begin{aligned}
 m\bigl((2^{-j}H_j)\cap[0,1]\bigr)
 &=2^{-j}m\bigl(H_j\cap[0,2^j]\bigr)=\rho(H_j),\\
 m\bigl((-2^{-j}H_j)\cap[0,1]\bigr)
 &=2^{-j}m\bigl(H_j\cap[-2^j,0]\bigr)=\rho(H_j).
\end{aligned}$$ Indeed, each interval on the right contains exactly $2^j$ unit periods; their endpoints do not affect Lebesgue measure. Countable subadditivity therefore yields $$m(C\cap[0,1])\le2\sum_{j\ge1}\rho(H_j)
     \le12\sum_{j\ge1}p_j=\frac{\eta}{2}.$$ Consequently $$m(E)=1-m(C\cap[0,1])\ge1-\frac{\eta}{2}>1-\eta.$$

It remains to show that every signed affine copy of $D$ meets $C$. Let $x\in\mathbb R$ and first suppose that $s>0$. Choose an integer $k$ with $$t=2^k s\in[1,2),$$ and set $j=\max\{1,k\}$. Apply <a href="#global:normalized-hits" data-reference-type="eqref" data-reference="global:normalized-hits">[global:normalized-hits]</a> to the center $2^j x$ and the normalized scale $t$. There is an integer $n\ge1$ such that $$2^j x+t2^{-n}\in H_j.$$ Multiplying by $2^{-j}$ gives $$x+s2^{-(n+j-k)}\in2^{-j}H_j\subset C.$$ The index $N=n+j-k$ is an integer and satisfies $N\ge n\ge1$, because $j\ge k$. Hence this point belongs to the original copy $x+sD$. The argument applies to every real center and every positive scale, including arbitrarily small scales, for which larger values of $j$ are available.

If $s<0$, apply the positive-scale conclusion to the center $-x$ and scale $-s$. For some integer $N\ge1$, $$-(x+s2^{-N})=(-x)+(-s)2^{-N}\in C.$$ Since $-C=C$, it follows that $x+s2^{-N}\in C$ as well. In either case, the copy $x+sD$ has a point in $C$, which is disjoint from $E$. Thus the fixed compact set $E$ excludes every such copy, as required. ◻

</details>
