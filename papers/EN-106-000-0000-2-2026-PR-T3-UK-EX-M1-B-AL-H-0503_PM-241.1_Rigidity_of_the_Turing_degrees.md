## 1. Abstract and result contract

> We prove that every order automorphism of the full partial order of Turing degrees is the identity, resolving the rigidity conjecture for the Turing degrees positively.

- **C1** (theorem, [source](#stmt-thm-rigidity)): Every order automorphism of the full Turing-degree structure is the identity: $$\forall\pi\in\mathop{\mathrm{Aut}}(\mathcal D_T,\le_T)\ \forall\mathbf a\in\mathcal D_T \qquad \pi(\mathbf a)=\mathbf a.$$
  - Explanation: Every arbitrary order automorphism fixes every degree in the full Turing-degree ordering; the source asserts this in ZFC without regularity assumptions on the automorphism.
- **C2** (construction, [source](#stmt-lem-cuts)): The cut map $C:\mathbb R\to2^\mathbb N$ is Borel and injective. If $c_0,\ldots,c_k\in\mathbb Q$ and $x_1,\ldots,x_k\in\mathbb R$, with $k\ge1$, then $$d\left(c_0+\sum_{i=1}^k c_ix_i\right) \le_T\bigvee_{i=1}^k d(x_i).$$ Every noncomputable degree equals $d(t)$ for some irrational $t\in(0,1)$.
  - Explanation: Strict rational cuts are Borel and injective, rational affine combinations satisfy the stated degree inequality, and irrational cuts in the unit interval represent every noncomputable degree.
- **C3** (conditional_result, [source](#stmt-lem-continuity)): If $X$ is Polish, $Y$ is second countable, and $f:X\to Y$ is Borel, there is a comeager set $D\subseteq X$ such that $f\|D$ is continuous.
  - Explanation: A Borel function has a continuous restriction to a comeager set; continuity on the ambient space is not asserted.
- **C4** (conditional_result, [source](#stmt-lem-avoidance)): Let $A,Y\subseteq\mathbb N$ with $Y\not\le_TA$. Then $$\{(u,v)\in\mathbb R^2:Y\le_TA\oplus C(u)\oplus C(v)\}$$ is meager.
  - Explanation: For a target not reducible to the fixed base oracle, auxiliary rational cuts compute that target only on a meager set of real pairs, allowing varying reduction indices.
- **C5** (theorem, [source](#stmt-thm-representation)): For every $\pi\in\mathop{\mathrm{Aut}}(\mathcal D_T,\le_T)$ there is an arithmetic function $\widehat F:2^\mathbb N\to2^\mathbb N$ such that $$[\widehat F(A)]_T=\pi([A]_T) \qquad\text{for every }A\subseteq\mathbb N.$$
  - Explanation: The external Slaman–Woodin input supplies a single total arithmetic representation of an arbitrary automorphism on all sets of integers, rather than only generic inputs.
- **C6** (construction, [source](#stmt-lem-lift)): For an arbitrary $\pi\in\mathop{\mathrm{Aut}}(\mathcal D_T,\le_T)$ there is a Borel function $F:\mathbb R\to2^\mathbb N$ with countable fibers such that $$\begin{aligned} _T&=\pi(d(x))\qquad(x\in\mathbb R),\label{eq:representation}\\ F(x+y)&\le_TF(x)\oplus F(y)\qquad(x,y\in\mathbb R). \label{eq:addition} \end{aligned}$$
  - Explanation: The lift is asserted to be Borel, have countable fibers, induce the automorphism on real-cut degrees, and satisfy addition reducibility. The first displayed equation in the supplied repaired statement is malformed; its bytes are retained without correction.
- **C7** (conditional_result, [source](#stmt-prop-recovery)): Let $F:\mathbb R\to2^\mathbb N$ be Borel with countable fibers, and suppose $$F(x+y)\le_TF(x)\oplus F(y)\qquad(x,y\in\mathbb R).$$ For every irrational $t\in(0,1)$ there is a comeager set $G_t\subseteq\mathbb R^2$ such that for each $(u,v)\in G_t$ there is a rational $\delta\in(0,1)$ for which $$\label{eq:four-values} C(t)\le_T F(u)\oplus F(u-v)\oplus F(v-u+\delta t)\oplus F(v-u+\delta(t-1)).$$
  - Explanation: An irrational cut is reducible to the join of four prescribed function values on a comeager set of auxiliary pairs, with a rational scale and reduction program chosen pointwise.
- **C8** (conditional_result, [source](#stmt-rem-nonuniform)): The parameter $\delta$ and the reduction program in Proposition <a href="#prop:recovery" data-reference-type="ref" data-reference="prop:recovery">7</a> need not be selected effectively from $(u,v)$. The conclusion is that the reduction exists for every pair in a comeager set. The category avoidance argument allows precisely this form of nonuniformity.
  - Explanation: The recovery statement is pointwise and does not provide an effective selector for its rational parameter or program from the auxiliary pair.
- **C9** (theorem, [source](#stmt-cor-biinterpretability)): The Turing-degree ordering is biinterpretable without parameters with full second-order arithmetic, in the sense of [[SlamanWoodin2005](#ref-SlamanWoodin2005), Definition 7.5.1].
  - Explanation: The parameter-free biinterpretability corollary uses the external equivalence between the stated biinterpretability property and rigidity.

## 2. Definitions, validity and bounds

- **Turing reducibility** ([source](#sec:introduction)): Turing reducibility compares the information available from sets of integers: $A\le_TB$ means that an oracle Turing machine with oracle $B$ computes the characteristic function of $A$.
- **Turing degrees** ([source](#sec:introduction)): Mutual reducibility defines Turing equivalence, and its equivalence classes form the partial order $(\mathcal D_T,\le_T)$ of Turing degrees.
- **Order automorphism** ([source](#sec:introduction)): An automorphism here is any bijection $\pi:\mathcal D_T\to\mathcal D_T$ satisfying $$\mathbf a\le_T\mathbf b \quad\Longleftrightarrow\quad \pi(\mathbf a)\le_T\pi(\mathbf b).$$
- **Oracle join** ([source](#sec:preliminaries)): For sets $A,B$, their join $A\oplus B$ interleaves their characteristic functions.
- **Degree join** ([source](#sec:preliminaries)): The degree join $\mathbf a\vee\mathbf b$ is the least upper bound of $\mathbf a,\mathbf b$: an oracle computes $A\oplus B$ exactly when it computes both $A$ and $B$.
- **Strict rational cut and real degree** ([source](#sec:preliminaries)): To distinguish ordinary real numbers from oracle sets, fix an effective listing $(q_i)_{i\in\mathbb N}$ of $\mathbb Q$ and put $$C(x)=\{i:q_i<x\},\qquad d(x)=[C(x)]_T \quad(x\in\mathbb R).$$
- **Recurrence choices and states** ([source](#eq:recurrence)): Define $s_0=0$ and, recursively, $$\label{eq:recurrence} r_n= \begin{cases} 1,&F(u+s_n)(j)=h,\\ 0,&F(u+s_n)(j)\ne h, \end{cases} \qquad s_{n+1}=s_n+\delta(t-r_n).$$

## 3. Proof roadmap

- **R1** [claim](#stmt-lem-cuts) / [proof](#proof-stmt-lem-cuts): Rational-cut coding and pointwise rational approximation. -> Borel injection, affine degree bounds, and irrational representatives of noncomputable degrees.
- **R2** [claim](#stmt-lem-continuity) / [proof](#proof-stmt-lem-continuity): Baire-property open approximations for preimages of a countable basis. -> Continuity on a comeager restriction.
- **R3** [claim](#stmt-lem-avoidance) / [proof](#proof-stmt-lem-avoidance): Finite oracle-transcript search and density contradiction, followed by a countable union over indices. -> Meagerness of the auxiliary-pair computation cone.
- **R4** [claim](#stmt-thm-representation) / [proof](#sec:representation): Invoke the external all-input arithmetic representation theorem and Borel-graph criterion. -> Single all-input Borel representative on sets of integers.
- **R5** [claim](#stmt-lem-lift) / [proof](#proof-stmt-lem-lift): Compose the representative with the cut map and use order and join preservation. -> Countable-fiber Borel real map with addition reducibility.
- **R6** [claim](#stmt-prop-recovery) / [proof](#proof-stmt-prop-recovery): Intersect countably many shifted comeager conditions and freeze two local addition indices. -> Comeager auxiliary pairs and pointwise local program constants.
- **R7** [claim](#stmt-prop-recovery) / [proof](#eq:invariant): Inward endpoint strips and exact telescoping of the bounded recurrence. -> Confined states and branch-average convergence.
- **R8** [claim](#stmt-prop-recovery) / [proof](#proof-stmt-prop-recovery): Effective oracle-subroutine substitution and rational-cut separation using the convergence bound. -> Pointwise reduction of the irrational cut to the four-value join.
- **R9** [claim](#stmt-thm-rigidity) / [proof](#proof-stmt-rem-nonuniform): Apply the inverse automorphism to the recovery bound, remove auxiliary parameters by category avoidance, and repeat for the inverse. -> Identity of every full degree-order automorphism.
- **R10** [claim](#stmt-cor-biinterpretability) / [proof](#proof-stmt-cor-biinterpretability): Use the externally cited equivalence with rigidity. -> Parameter-free biinterpretability with full second-order arithmetic.

## 4. Engineering Triptych

### Panel 1 - epistemic contract

- **P3-I-rigidity**: Every order automorphism fixes every degree.
- **P3-I-recovery**: The rational cut of the irrational parameter is Turing reducible to the join of the four specified F-values for each auxiliary pair in the stated comeager set, with a suitable rational step.
- **P3-I-confinement**: The recurrence remains in its chosen endpoint interval when the tested bit forces inward steps in the endpoint strips.
- **P3-I-nonuniform**: The recovery establishes a pointwise reduction and does not require a runtime bound or uniform program constants.

### Panel 2 - negative knowledge

- **P3-A-finite-order**: Conclude that a finite software dependency order has no nontrivial automorphisms. -> Rigidity of the full Turing-degree ordering does not establish rigidity of another ordered structure.
- **P3-A-uniform**: Compile recovery into a uniform decoder taking only the auxiliary reals as inputs. -> The source does not provide an effective selection procedure for the step or reduction program.
- **P3-A-simulation**: Use finite recurrence samples as a certificate of irrational-cut recovery or global rigidity. -> A finite trace cannot establish total oracle computation, comeagerness, or the universal order-automorphism conclusion.
- **P3-A-latency**: Treat the effective averaging error bound as a wall-clock runtime guarantee. -> The error controls accuracy by recurrence index; nested oracle computations have no source runtime bound.

<a id="sec:introduction"></a>
### Introduction

Turing reducibility compares the information available from sets of integers: $A\le_TB$ means that an oracle Turing machine with oracle $B$ computes the characteristic function of $A$. Mutual reducibility defines Turing equivalence, and its equivalence classes form the partial order $(\mathcal D_T,\le_T)$ of Turing degrees. The underlying notion of relative computation goes back to Turing’s oracle machines <a id="pm-cite-1"></a>[[Turing1939](#ref-Turing1939), Section 4]; see <a id="pm-cite-2"></a>[[Soare1987](#ref-Soare1987)] for standard degree-theoretic background. The automorphism problem asks how much of this information the abstract ordering retains.

The rigidity conjecture for the Turing degrees asks whether every automorphism of this ordering fixes every degree. An automorphism here is any bijection $\pi:\mathcal D_T\to\mathcal D_T$ satisfying $$\mathbf a\le_T\mathbf b
\quad\Longleftrightarrow\quad
\pi(\mathbf a)\le_T\pi(\mathbf b).$$ We work in ZFC and impose no definability or regularity hypothesis on $\pi$.

<a id="stmt-thm-rigidity"></a>
<div id="thm:rigidity" class="theorem">

**Theorem 1**. *Every order automorphism of the full Turing-degree structure is the identity: $$\forall\pi\in\mathop{\mathrm{Aut}}(\mathcal D_T,\le_T)\ \forall\mathbf a\in\mathcal D_T
\qquad \pi(\mathbf a)=\mathbf a.$$*

</div>

<a id="pm-h-3"></a>
###### Prior work and the remaining problem.

The Turing jump sends a degree $\mathbf a$ to the degree $\mathbf a'$ of the halting problem relative to an oracle of degree $\mathbf a$. Jockusch and Solovay proved that every jump-preserving order automorphism fixes all degrees above $\mathbf0^{(4)}$, the fourth jump of the computable degree <a id="pm-cite-3"></a>[[JockuschSolovay1977](#ref-JockuschSolovay1977)]. Using Slaman and Woodin’s definability of the double jump, Shore and Slaman proved that the jump is definable from the ordering <a id="pm-cite-4"></a>[[ShoreSlaman1999](#ref-ShoreSlaman1999)], so every order automorphism preserves it. Shore later gave direct degree-theoretic definitions of the jump <a id="pm-cite-5"></a>[[Shore2007](#ref-Shore2007)].

A cone consists of all degrees above a fixed degree. Nerode and Shore proved that every automorphism fixes some cone, whose base may depend on the automorphism <a id="pm-cite-6"></a>[[NerodeShore1980](#ref-NerodeShore1980)]; see also <a id="pm-cite-7"></a>[[SlamanGlobal](#ref-SlamanGlobal), Theorem 3.2, author's version]. Slaman and Woodin obtained a fixed cone common to all automorphisms: every automorphism fixes all degrees above $\mathbf0''$, the second jump of the computable degree. Their analysis also shows that the automorphism group is countable and that each automorphism has an arithmetic representation on sets of integers <a id="pm-cite-8"></a>[[SlamanWoodin2005](#ref-SlamanWoodin2005), [SlamanGlobal](#ref-SlamanGlobal)]. These results show that the order determines substantial computability-theoretic structure. They leave the rigidity problem at degrees outside the known fixed cone.

The representation theorem is the external input to our proof. In its all-input form, it assigns to every arbitrary degree automorphism a single arithmetic, hence Borel, function on sets of integers that induces that automorphism on degrees <a id="pm-cite-9"></a>[[SlamanWoodin2005](#ref-SlamanWoodin2005), Theorem 6.3.1(2)]. The cited source is the 2005 unpublished manuscript; the result also appears in Slaman’s account <a id="pm-cite-10"></a>[[SlamanGlobal](#ref-SlamanGlobal)]. This theorem supplies the regularity needed for a category argument while retaining the unrestricted scope of Theorem <a href="#thm:rigidity" data-reference-type="ref" data-reference="thm:rigidity">1</a>.

<a id="pm-h-4"></a>
###### A consequence for definability.

Theorem <a href="#thm:rigidity" data-reference-type="ref" data-reference="thm:rigidity">1</a> also settles the biinterpretability conjecture of Slaman and Woodin. Full second-order arithmetic is the two-sorted structure of natural numbers and all subsets of natural numbers, with arithmetic and membership. Slaman and Woodin interpret this structure using finite tuples of Turing degrees. In their formulation, biinterpretability asks whether the relation matching such a code for a set $X\subseteq\mathbb N$ with its degree $[X]_T$ is first-order definable in the degree ordering without parameters <a id="pm-cite-11"></a>[[SlamanWoodin2005](#ref-SlamanWoodin2005), Definition 7.5.1]. They prove that this is equivalent to rigidity <a id="pm-cite-12"></a>[[SlamanWoodin2005](#ref-SlamanWoodin2005), Theorem 7.5.3]; thus our theorem gives a positive answer. We state the resulting corollary in Section <a href="#sec:rigidity" data-reference-type="ref" data-reference="sec:rigidity">5</a>.

<a id="pm-h-5"></a>
###### Recovery and removal of parameters.

Our main construction is the recovery theorem of Proposition <a href="#prop:recovery" data-reference-type="ref" data-reference="prop:recovery">7</a>. We identify $2^\mathbb N$ with the sets of integers; recovering a real means computing which rational numbers lie below it. Write $\oplus$ for the oracle join, which combines the information in finitely many sets of integers. For a Borel map $F:\mathbb R\to2^\mathbb N$ with countable fibers satisfying $$F(x+y)\le_TF(x)\oplus F(y),$$ we recover any prescribed irrational $t\in(0,1)$ from four values of $F$ at rational affine combinations of $t$ and two auxiliary reals $u,v$. Recovery holds for a comeager set of pairs $(u,v)$: the exceptional pairs form a countable union of nowhere-dense sets. The statement applies beyond functions representing degree automorphisms.

The numerical mechanism is an averaging identity. For a fixed positive rational $\delta$, start with a real state $s_0=0$ and repeatedly choose the increment $\delta t$ or $\delta(t-1)$, recording the choice as $r_n=0$ or $r_n=1$, respectively. Summing these increments gives $$s_N=\delta\left(Nt-\sum_{n<N}r_n\right).$$ If the states remain in $(-1,1)$, the proportion of choices with $r_n=1$ approximates $t$ with error less than $1/(N\delta)$. Thus computing the binary choices suffices to recover the irrational parameter $t$ with an effective error bound.

The function $F$ supplies both a rule for choosing the increments and a way to compute those choices. Countable fibers ensure that $F$ takes distinct values on opposite sides of $u$. Continuity on a comeager restriction then makes one output bit take opposite values near two such points. At state $s_n$, we test this bit of $F(u+s_n)$, choosing an upward step near the lower endpoint and a downward step near the upper endpoint. This keeps the states bounded, regardless of the bit’s behavior between the two endpoint regions.

The addition reductions need not be uniform in their inputs. For each auxiliary pair in a comeager set, Borel regularity provides two programs that remain fixed along the recurrence. The first adds the selected increment while moving from a neighborhood of $u$ to a neighborhood of $v$; the second returns to the neighborhood of $u$ at the new offset. The computation uses a fixed function value for each of the two possible increments, a fixed return value, and the initial value $F(u)$. These four values are its only real oracles. The program indices and rational constants may depend on $t$ and the chosen pair $(u,v)$.

Finite-oracle recovery also appears in perfect-set coding. Groszek and Slaman recover a real from two branches of a perfect tree together with a sequence supplying a suitable dense set <a id="pm-cite-13"></a>[[GroszekSlaman1998](#ref-GroszekSlaman1998), Lemma 2.2, author's version]. Lutz and Siskind’s refinement recovers any real from four elements of a perfect set together with a fixed real that computes each member of a countable dense subset, without requiring an enumeration computable from that fixed real <a id="pm-cite-14"></a>[[LutzSiskind2025](#ref-LutzSiskind2025), Theorem 4.3, arXiv version]. Our recovery statement has different hypotheses: it uses the addition relation for one Borel function and prescribes affine arguments for its four values. Its bounded recurrence supplies the decoding procedure without an additional real oracle.

To conclude rigidity, represent an arbitrary automorphism by a map $F$ as above. The degrees of the four arguments are bounded by the join of the degrees of $t,u,v$. Applying the inverse automorphism to the recovery bound therefore bounds the preimage degree of $t$ by this same join. Sacks’s relative category cone-avoidance principle says that, over a fixed oracle, auxiliary reals compute a fixed set not already computable from that oracle only on a meager set of choices <a id="pm-cite-15"></a>[[KumarShelah2023](#ref-KumarShelah2023), Lemma 4.1]. Since recovery holds on a comeager set, Lemma <a href="#lem:avoidance" data-reference-type="ref" data-reference="lem:avoidance">4</a> removes the auxiliary degrees and yields $\pi^{-1}(\mathbf a)\le_T\mathbf a$ for every degree $\mathbf a$. Applying $\pi$ to this inequality and repeating the argument for $\pi^{-1}$ gives the opposite inequalities between $\pi(\mathbf a)$ and $\mathbf a$.

A related method appears in Kjos-Hanssen’s proof of rigidity for automorphisms induced by permutations of the natural numbers <a id="pm-cite-16"></a>[[KjosHanssen2018](#ref-KjosHanssen2018), Theorem 20, arXiv version]. That argument recovers a Bernoulli parameter (the probability of a $1$), uses a measure cone theorem, and applies the inverse automorphism. Here the parameter is recovered from the addition relation for a Borel function, and category removes the auxiliary degrees. The representing function need not arise from a permutation.

### Computability and category

We first encode ordinary real arithmetic by Turing degrees. The category lemma at the end of the section will remove the auxiliary real parameters introduced by the recovery construction.

We identify $2^\mathbb N$ with the sets of natural numbers, equipped with the usual Cantor topology. Fix an effective enumeration $(\Phi_e)_{e\in\mathbb N}$ of oracle Turing machines. For sets $A,B$, their join $A\oplus B$ interleaves their characteristic functions. Finite joins use a fixed effective coding.

The degree join $\mathbf a\vee\mathbf b$ is the least upper bound of $\mathbf a,\mathbf b$: an oracle computes $A\oplus B$ exactly when it computes both $A$ and $B$. Every order automorphism therefore preserves finite joins. It also fixes the least degree $\mathbf0$.

To distinguish ordinary real numbers from oracle sets, fix an effective listing $(q_i)_{i\in\mathbb N}$ of $\mathbb Q$ and put $$C(x)=\{i:q_i<x\},\qquad d(x)=[C(x)]_T
\quad(x\in\mathbb R).$$ Thus all computability assertions about real numbers below refer to these strict rational cuts.

<a id="stmt-lem-cuts"></a>
<div id="lem:cuts" class="lemma">

**Lemma 2**. *The cut map $C:\mathbb R\to2^\mathbb N$ is Borel and injective. If $c_0,\ldots,c_k\in\mathbb Q$ and $x_1,\ldots,x_k\in\mathbb R$, with $k\ge1$, then $$d\left(c_0+\sum_{i=1}^k c_ix_i\right)
\le_T\bigvee_{i=1}^k d(x_i).$$ Every noncomputable degree equals $d(t)$ for some irrational $t\in(0,1)$.*

</div>

<details id="proof-stmt-lem-cuts"><summary>Proof of stmt-lem-cuts</summary>

*Proof.* The $i$th coordinate of $C$ is the indicator of the open ray $(q_i,\infty)$, so $C$ is Borel. Density of $\mathbb Q$ gives injectivity.

An oracle for $C(x)$ computes rational brackets $a<x\le b$ of arbitrarily small width: search over rational pairs and check their cut bits. The input cuts consequently compute rational approximations, with prescribed error, to any fixed rational linear combination $z$. If $z$ is irrational, comparison with each rational query eventually separates and computes $C(z)$. If $z$ is rational, its cut is computable. This proves the degree inequality. It asserts existence of a reduction for each fixed tuple, and does not require an algorithm deciding whether the combination is rational.

Given a noncomputable set $B$, let $t=\sum_{n\ge0}B(n)2^{-n-1}$. Then $0<t<1$ and $t$ is irrational: the endpoint expansions and all binary expansions of rational numbers are computable. The bits of $B$ give effective approximations to $t$, hence compute $C(t)$ by irrationality. Conversely, successive dyadic comparisons with the cut recover the unique binary expansion of $t$. Thus $C(t)\equiv_TB$. ◻

</details>

Recall that a set is *meager* if it is a countable union of nowhere-dense sets, and *comeager* if its complement is meager. We use the Baire Category Theorem and the fact that Borel sets in Polish spaces have the Baire property <a id="pm-cite-17"></a>[[MarkerDST](#ref-MarkerDST), Theorem 2.52 and Corollary 2.57].

<a id="stmt-lem-continuity"></a>
<div id="lem:continuity" class="lemma">

**Lemma 3**. *If $X$ is Polish, $Y$ is second countable, and $f:X\to Y$ is Borel, there is a comeager set $D\subseteq X$ such that $f|D$ is continuous.*

</div>

<details id="proof-stmt-lem-continuity"><summary>Proof of stmt-lem-continuity</summary>

*Proof.* Let $(U_n)$ be a countable basis for $Y$. By the Baire property, write $f^{-1}(U_n)\mathbin{\triangle}V_n\subseteq M_n$, where $V_n$ is open and $M_n$ is meager. On $D=X\setminus\bigcup_nM_n$ one has $(f|D)^{-1}(U_n)=D\cap V_n$, which is relatively open. ◻

</details>

Only continuity on the indicated restriction is asserted. For a discrete-valued function, Lemma <a href="#lem:continuity" data-reference-type="ref" data-reference="lem:continuity">3</a> makes its value constant on the intersection of that restriction with a suitable neighborhood of each of its points.

Lemma <a href="#lem:avoidance" data-reference-type="ref" data-reference="lem:avoidance">4</a> will remove auxiliary real parameters from a degree bound that holds on a comeager set of pairs. It is the relative category cone-avoidance principle attributed to Sacks in <a id="pm-cite-18"></a>[[KumarShelah2023](#ref-KumarShelah2023), Lemma 4.1]. We include the version for rational-cut oracles that our proof requires.

<a id="stmt-lem-avoidance"></a>
<div id="lem:avoidance" class="lemma">

**Lemma 4** (Category avoidance). *Let $A,Y\subseteq\mathbb N$ with $Y\not\le_TA$. Then $$\{(u,v)\in\mathbb R^2:Y\le_TA\oplus C(u)\oplus C(v)\}$$ is meager.*

</div>

<details id="proof-stmt-lem-avoidance"><summary>Proof of stmt-lem-avoidance</summary>

*Proof.* For a fixed index $e$, let $S_e$ be the set of pairs with both coordinates irrational for which $\Phi_e^{A\oplus C(u)\oplus C(v)}$ is the characteristic function of $Y$. Suppose $S_e$ is dense in a nonempty open rectangle $R$ with rational endpoints. We show that $Y\le_TA$, with $e$ and the endpoints of $R$ as finite program constants.

On input $n$, search for a finite halting computation of $\Phi_e(n)$ whose answers about $A$ are correct and whose finitely many proposed cut answers hold throughout a nonempty open subrectangle of $R$. This is an effective search relative to $A$. Dovetail simulations with finite time bounds and finite tables of proposed answers to the two variable oracles. For a cut $C(u)$, answer $1$ to a rational $q$ imposes $q<u$, whereas answer $0$ imposes $u\le q$. Such a finite table is compatible throughout a nonempty open interval inside the corresponding side of $R$ exactly when the maximum of its lower bounds is smaller than the minimum of its upper bounds, after including the corresponding endpoints of $R$ among these bounds. This is decidable rational arithmetic, and the same check applies to $v$. Repeated queries must have consistent answers.

The search terminates. A pair in $S_e\cap R$ has a halting computation on $n$. Since its coordinates are irrational, none of the finitely many queried rationals equals the relevant coordinate. Its finite transcript therefore holds on an open neighborhood inside $R$, and appears in the search. Every transcript accepted by the search is sound: its open subrectangle intersects the dense set $S_e$, where the same deterministic computation returns $Y(n)$. The search thus computes $Y(n)$ with oracle $A$, a contradiction.

It follows that $S_e$ is not dense in any nonempty rational open rectangle. Since these rectangles form a basis, $S_e$ is nowhere dense. The pairs with a rational coordinate form a countable union of nowhere-dense lines. Adding these pairs and taking the countable union over $e$ completes the proof. ◻

</details>

The reduction index in Lemma <a href="#lem:avoidance" data-reference-type="ref" data-reference="lem:avoidance">4</a> may depend on $(u,v)$. Its proof takes the union over all indices, so no uniformity across the success set is required.

<a id="sec:representation"></a>
### Representing an arbitrary automorphism

We invoke the following established result. Its scope is essential: it applies to any automorphism of the full degree order and supplies a single function valid at every input.

<a id="stmt-thm-representation"></a>
<div id="thm:representation" class="theorem">

**Theorem 5** (Slaman–Woodin). *For every $\pi\in\mathop{\mathrm{Aut}}(\mathcal D_T,\le_T)$ there is an arithmetic function $\widehat F:2^\mathbb N\to2^\mathbb N$ such that $$[\widehat F(A)]_T=\pi([A]_T)
\qquad\text{for every }A\subseteq\mathbb N.$$*

</div>

This is Theorem 6.3.1(2) of <a id="pm-cite-19"></a>[[SlamanWoodin2005](#ref-SlamanWoodin2005)]; see also Theorem 4.29 in the author version of <a id="pm-cite-20"></a>[[SlamanGlobal](#ref-SlamanGlobal)]. The generic-input assertion in the first clause of the cited Theorem 6.3.1 is separate from the all-input assertion used here.

Arithmetic here describes the graph of a single total function. That graph is Borel. By the Borel-graph criterion for functions between Polish spaces <a id="pm-cite-21"></a>[[MarkerDST](#ref-MarkerDST), Corollary 4.15], $\widehat F$ is Borel. The weaker Borel conclusion also appears directly as Corollary 4.25 in the author version of <a id="pm-cite-22"></a>[[SlamanGlobal](#ref-SlamanGlobal)].

<a id="stmt-lem-lift"></a>
<div id="lem:lift" class="lemma">

<a id="eq:representation"></a>
<a id="eq:addition"></a>
**Lemma 6**. *For an arbitrary $\pi\in\mathop{\mathrm{Aut}}(\mathcal D_T,\le_T)$ there is a Borel function $F:\mathbb R\to2^\mathbb N$ with countable fibers such that $$\begin{aligned}
_T&=\pi(d(x))\qquad(x\in\mathbb R),\label{eq:representation}\\
F(x+y)&\le_TF(x)\oplus F(y)\qquad(x,y\in\mathbb R).
\label{eq:addition}
\end{aligned}$$*

</div>

<details id="proof-stmt-lem-lift"><summary>Proof of stmt-lem-lift</summary>

*Proof.* Take $F=\widehat F\circ C$ from Theorem <a href="#thm:representation" data-reference-type="ref" data-reference="thm:representation">5</a> and Lemma <a href="#lem:cuts" data-reference-type="ref" data-reference="lem:cuts">2</a>. If $F(x)=F(y)$, then $\pi(d(x))=\pi(d(y))$, hence $d(x)=d(y)$. Each fiber of $F$ therefore injects, by $C$, into a single Turing degree. Such a degree is countable: its members are among the outputs of countably many oracle programs with any fixed representative as oracle.

By Lemma <a href="#lem:cuts" data-reference-type="ref" data-reference="lem:cuts">2</a>, $d(x+y)\le_Td(x)\vee d(y)$. Since $\pi$ preserves order and joins, $$[F(x+y)]_T
\le_T\pi(d(x))\vee\pi(d(y))
=[F(x)\oplus F(y)]_T.$$ This is exactly <a href="#eq:addition" data-reference-type="eqref" data-reference="eq:addition">[eq:addition]</a>. ◻

</details>

The representing function is not required to be injective, or to give the same output set on equivalent input sets. Equation <a href="#eq:representation" data-reference-type="eqref" data-reference="eq:representation">[eq:representation]</a> prescribes only its output degree. The countable-fiber property is the consequence of injectivity of the automorphism that will enter the argument.

<a id="sec:recovery"></a>
### Recovery from four values

The following result separates the local construction from the degree automorphism to which it will be applied.

<a id="stmt-prop-recovery"></a>
<div id="prop:recovery" class="proposition">

<a id="eq:four-values"></a>
**Proposition 7** (Recovery from four values). *Let $F:\mathbb R\to2^\mathbb N$ be Borel with countable fibers, and suppose $$F(x+y)\le_TF(x)\oplus F(y)\qquad(x,y\in\mathbb R).$$ For every irrational $t\in(0,1)$ there is a comeager set $G_t\subseteq\mathbb R^2$ such that for each $(u,v)\in G_t$ there is a rational $\delta\in(0,1)$ for which $$\label{eq:four-values}
C(t)\le_T
F(u)\oplus F(u-v)\oplus
F(v-u+\delta t)\oplus F(v-u+\delta(t-1)).$$*

</div>

<details id="proof-stmt-prop-recovery"><summary>Proof of stmt-prop-recovery</summary>

*Proof.* The two auxiliary reals allow us to advance from $u+s$ to $u+s+a$ through two additions: $$(u+s)+(v-u+a)=v+s+a,\qquad
(v+s+a)+(u-v)=u+s+a.$$ If the programs witnessing these additions can be kept fixed, then the oracles $F(v-u+a)$ and $F(u-v)$ turn an oracle for $F(u+s)$ into one for $F(u+s+a)$. We will use only the two increments $\delta t$ and $\delta(t-1)$. The initial oracle $F(u)$, the fixed return oracle $F(u-v)$, and the two increment oracles are exactly the four values in <a href="#eq:four-values" data-reference-type="eqref" data-reference="eq:four-values">[eq:four-values]</a>. For each pair $(u,v)$ in a comeager set, we first arrange two programs that remain fixed along the recurrence. A bit of $F(u+s)$ will then select the increment so that successive states stay bounded; the frequencies of the choices will recover $t$.

*Two local addition programs.* For each $(x,y)$, let $e(x,y)$ be the least index satisfying $$\Phi_{e(x,y)}^{F(x)\oplus F(y)}=F(x+y).$$ Such an index exists by hypothesis. For a fixed index, the condition that every output bit is computed correctly is arithmetical in the three oracle sets and is therefore Borel in $(x,y)$. The set on which this is the least successful index is Borel as well. Thus $e:\mathbb R^2\to\mathbb N$ is Borel.

<a id="eq:all-shifts"></a>
By Lemma <a href="#lem:continuity" data-reference-type="ref" data-reference="lem:continuity">3</a>, choose comeager sets $D\subseteq\mathbb R$ and $E\subseteq\mathbb R^2$ such that $F|D$ and $e|E$ are continuous; the codomain of $e$ is discrete. Fix the given $t$ and put $H=\mathbb Q+\mathbb Qt$. Let $G_t$ consist of the pairs $(u,v)$ satisfying $$\label{eq:all-shifts}
u+s\in D,\qquad
(u+s,v-u+a)\in E,\qquad
(v+s,u-v)\in E
\quad\text{for all }s,a\in H.$$ The group $H$ is countable. For each fixed pair of shifts, the last two maps of $(u,v)$ in <a href="#eq:all-shifts" data-reference-type="eqref" data-reference="eq:all-shifts">[eq:all-shifts]</a> are affine homeomorphisms of $\mathbb R^2$. The first condition is a pullback under a translated coordinate projection; the inverse image of a meager exceptional set is meager. Consequently $G_t$ is comeager.

<a id="eq:p"></a>
<a id="eq:q"></a>
Fix any $(u,v)\in G_t$, and set $$p=e(u,v-u),\qquad q=e(v,u-v).$$ Both centers belong to $E$. Relative continuity of $e|E$ gives a number $0<\rho<1$ such that $$\begin{aligned}
e(u+s,v-u+a)&=p
&& (s,a\in H,\ |s|,|a|<\rho),\label{eq:p}\\
e(v+s,u-v)&=q
&& (s\in H,\ |s|<\rho).\label{eq:q}
\end{aligned}$$ The membership in $E$ required for these equalities is supplied by <a href="#eq:all-shifts" data-reference-type="eqref" data-reference="eq:all-shifts">[eq:all-shifts]</a>. Thus $p$ and $q$ carry out the two additions above whenever $s,a\in H$ and $|s|,|a|,|s+a|<\rho$. The last bound is needed because the second addition starts at the new offset $s+a$. We now choose the two increments and a rule for selecting between them so that the old and new offsets always stay in this range.

*A bounded recurrence.* Choose $-\rho<b_-<0$ with $u+b_-\in D$. The interval $(0,\rho)$ contains uncountably many $b$ with $u+b\in D$, and the fiber of $F(u+b_-)$ is countable. We may therefore choose $0<b_+<\rho$ with $u+b_+\in D$ and $F(u+b_-)\ne F(u+b_+)$. Fix a bit $j$ where these two sets differ, and put $h=F(u+b_+)(j)$.

<a id="eq:left"></a>
<a id="eq:right"></a>
Continuity of $F|D$ makes this bit constant on sufficiently small relative neighborhoods of the two endpoint translates. Choose a positive rational $\delta<\rho$ small enough that $$\begin{aligned}
F(u+s)(j)&\ne h
&&\bigl(s\in H\cap[b_-,b_-+\delta]\bigr),\label{eq:left}\\
F(u+s)(j)&=h
&&\bigl(s\in H\cap[b_+-\delta,b_+]\bigr).\label{eq:right}
\end{aligned}$$ We may also require $3\delta<b_+-b_-$. Every tested translate belongs to $D$ by <a href="#eq:all-shifts" data-reference-type="eqref" data-reference="eq:all-shifts">[eq:all-shifts]</a>; the endpoints themselves need not lie in $H$.

<a id="eq:recurrence"></a>
<a id="eq:invariant"></a>
Define $s_0=0$ and, recursively, $$\label{eq:recurrence}
r_n=
\begin{cases}
1,&F(u+s_n)(j)=h,\\
0,&F(u+s_n)(j)\ne h,
\end{cases}
\qquad
s_{n+1}=s_n+\delta(t-r_n).$$ We claim that $$\label{eq:invariant}
s_n\in H\cap[b_-,b_+]\qquad(n\ge0).$$ The initial state has this property. If $r_n=0$, then <a href="#eq:right" data-reference-type="eqref" data-reference="eq:right">[eq:right]</a> forces $s_n<b_+-\delta$; the increment $\delta t$ lies in $(0,\delta)$, so $s_{n+1}$ remains in the interval. If $r_n=1$, then <a href="#eq:left" data-reference-type="eqref" data-reference="eq:left">[eq:left]</a> forces $s_n>b_-+\delta$; its negative increment has magnitude $\delta(1-t)<\delta$, with the same conclusion. Rationality of $\delta$ ensures $s_{n+1}\in H$. This proves <a href="#eq:invariant" data-reference-type="eqref" data-reference="eq:invariant">[eq:invariant]</a>, and in particular $|s_n|<\rho$. Figure <a href="#fig:bounded-recurrence" data-reference-type="ref" data-reference="fig:bounded-recurrence">1</a> isolates the only feature of the tested bit needed for this confinement: it points the next step inward near either endpoint. No restriction on its intervening behavior is needed.

<figure id="fig:bounded-recurrence">

<figcaption>The bounded recurrence, schematically. The tested bit forces an inward step in each endpoint strip; the bit need not be monotone between them. Each step has length less than $δ$, so no state can leave $[b_{−},b_{+}]$. The oracle computation produces the choices $r_{n}$, not the numerical states $s_{n}$.</figcaption>
</figure>

*Computing the binary choices.* Let $T$ denote the finite join on the right of <a href="#eq:four-values" data-reference-type="eqref" data-reference="eq:four-values">[eq:four-values]</a>. We show that $(r_n)_{n\ge0}$ is computable from $T$ by maintaining, relative to $T$, an oracle-program index $P_n$ satisfying $$\Phi_{P_n}^{T}=F(u+s_n).$$ Initially $P_0$ projects to the first component $F(u)$. Given $P_n$, read $\Phi_{P_n}^{T}(j)$ and compare it with the fixed bit $h$ to obtain $r_n$. Select the third component of $T$ if $r_n=0$ and the fourth if $r_n=1$, namely $$F(v-u+\delta(t-r_n)).$$

Set $a_n=\delta(t-r_n)$. By <a href="#eq:invariant" data-reference-type="eqref" data-reference="eq:invariant">[eq:invariant]</a>, $s_n,a_n\in H$ and $|s_n|,|a_n|<\rho$. Equation <a href="#eq:p" data-reference-type="eqref" data-reference="eq:p">[eq:p]</a> therefore shows that program $p$, with its two oracle components simulated by $\Phi_{P_n}^{T}$ and the selected tuple component, computes $$F(v+s_n+a_n)=F(v+s_{n+1}).$$ Since $|s_{n+1}|<\rho$, Equation <a href="#eq:q" data-reference-type="eqref" data-reference="eq:q">[eq:q]</a> then shows that program $q$, with this output and the fixed component $F(u-v)$ as its two oracles, computes $F(u+s_{n+1})$. Effective substitution of oracle subroutines produces the next index $P_{n+1}$.

This is an actual computation relative to the fixed tuple. The indices are constructed using the already computed branch bits. Inductively each substituted subroutine is total on its actual oracle, and both outer programs are valid reductions at the indicated argument pairs. Every bit computation has finite nesting depth through earlier indices and terminates. No bound on its running time is needed. To compute $r_n$, perform the finite construction through stage $n$.

The program uses only the fixed integers $p,q,j,h$, the rational $\delta$, and the four tuple components. It does not compute the numerical states $s_n$, or use $t,u,v,\rho,b_-,b_+$ as additional real oracles. The finite program constants may depend on $t,u,v$, as allowed in the pointwise reduction <a href="#eq:four-values" data-reference-type="eqref" data-reference="eq:four-values">[eq:four-values]</a>.

*Recovering the parameter.* Summing <a href="#eq:recurrence" data-reference-type="eqref" data-reference="eq:recurrence">[eq:recurrence]</a> gives $$s_N=\delta\left(Nt-\sum_{n<N}r_n\right).$$ Because $|s_N|<\rho<1$, the $T$-computable rational numbers $A_N=N^{-1}\sum_{n<N}r_n$ satisfy <a id="eq:error"></a>$$\label{eq:error}
|t-A_N|<\frac{1}{N\delta}\qquad(N\ge1).$$ For a rational query $a$, search for an $N$ such that $a<A_N-1/(N\delta)$ or $a>A_N+1/(N\delta)$, and return the corresponding cut bit. Irrationality of $t$ guarantees termination. The rational $\delta$ makes the error bound effective, so this computes $C(t)$ from $T$ and proves <a href="#eq:four-values" data-reference-type="eqref" data-reference="eq:four-values">[eq:four-values]</a>. ◻

</details>

*Remark 8*. The parameter $\delta$ and the reduction program in Proposition <a href="#prop:recovery" data-reference-type="ref" data-reference="prop:recovery">7</a> need not be selected effectively from $(u,v)$. The conclusion is that the reduction exists for every pair in a comeager set. The category avoidance argument allows precisely this form of nonuniformity.

</div>

<a id="sec:rigidity"></a>
### Rigidity and biinterpretability

We now apply the recovery construction to the full degree structure.

<details id="proof-stmt-rem-nonuniform"><summary>Proof of stmt-rem-nonuniform</summary>

*Proof of Theorem <a href="#thm:rigidity" data-reference-type="ref" data-reference="thm:rigidity">1</a>.* Fix an arbitrary order automorphism $\pi$ and take the Borel map $F$ given by Lemma <a href="#lem:lift" data-reference-type="ref" data-reference="lem:lift">6</a>. Fix an irrational $t\in(0,1)$. Proposition <a href="#prop:recovery" data-reference-type="ref" data-reference="prop:recovery">7</a> gives a comeager set $G_t$ of pairs $(u,v)$ for which <a href="#eq:four-values" data-reference-type="eqref" data-reference="eq:four-values">[eq:four-values]</a> holds with a suitable rational $\delta\in(0,1)$.

<a id="eq:generic-bound"></a>
For such a pair, put $\mathbf b=d(t)\vee d(u)\vee d(v)$. Each argument in the four values on the right of <a href="#eq:four-values" data-reference-type="eqref" data-reference="eq:four-values">[eq:four-values]</a> is a rational linear combination of $t,u,v,1$. Lemma <a href="#lem:cuts" data-reference-type="ref" data-reference="lem:cuts">2</a> bounds its degree by $\mathbf b$, and Equation <a href="#eq:representation" data-reference-type="eqref" data-reference="eq:representation">[eq:representation]</a> bounds the degree of its $F$-value by $\pi(\mathbf b)$. The same upper bound holds for the finite join of the four values. Thus $$d(t)\le_T\pi\bigl(d(t)\vee d(u)\vee d(v)\bigr)
\qquad((u,v)\in G_t).$$ Applying the inverse order automorphism yields $$\label{eq:generic-bound}
\pi^{-1}(d(t))\le_Td(t)\vee d(u)\vee d(v)
\qquad((u,v)\in G_t).$$

Choose one fixed set $Y$ representing $\pi^{-1}(d(t))$. If $Y\not\le_TC(t)$, Lemma <a href="#lem:avoidance" data-reference-type="ref" data-reference="lem:avoidance">4</a> says that $$\{(u,v):Y\le_TC(t)\oplus C(u)\oplus C(v)\}$$ is meager. But <a href="#eq:generic-bound" data-reference-type="eqref" data-reference="eq:generic-bound">[eq:generic-bound]</a> puts the comeager set $G_t$ inside this set, contradicting the Baire Category Theorem for $\mathbb R^2$. Consequently $$\pi^{-1}(d(t))\le_Td(t).$$ The set $Y$ is fixed before the pair varies. No common index for the reductions in <a href="#eq:generic-bound" data-reference-type="eqref" data-reference="eq:generic-bound">[eq:generic-bound]</a> is required.

<a id="eq:one-sided"></a>
The irrational $t$ was arbitrary. By Lemma <a href="#lem:cuts" data-reference-type="ref" data-reference="lem:cuts">2</a>, its degrees cover every noncomputable degree, and the least degree is fixed. We have therefore proved $$\label{eq:one-sided}
\pi^{-1}(\mathbf a)\le_T\mathbf a
\qquad(\mathbf a\in\mathcal D_T)$$ for every order automorphism $\pi$. Apply this result to the automorphism $\pi^{-1}$ to obtain $\pi(\mathbf a)\le_T\mathbf a$. Applying $\pi$ to <a href="#eq:one-sided" data-reference-type="eqref" data-reference="eq:one-sided">[eq:one-sided]</a> gives $\mathbf a\le_T\pi(\mathbf a)$. Antisymmetry now gives $\pi(\mathbf a)=\mathbf a$ for every degree. ◻

</details>

The second application uses Theorem <a href="#thm:representation" data-reference-type="ref" data-reference="thm:representation">5</a> for the inverse degree automorphism. It does not require an inverse of $F$, which may have nontrivial fibers.

<a id="stmt-cor-biinterpretability"></a>
<div id="cor:biinterpretability" class="corollary">

**Corollary 9**. *The Turing-degree ordering is biinterpretable without parameters with full second-order arithmetic, in the sense of <a id="pm-cite-23"></a>[[SlamanWoodin2005](#ref-SlamanWoodin2005), Definition 7.5.1].*

</div>
